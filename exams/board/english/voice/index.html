Q1 FREE PREVIEW

Veena had written a letter.

(Choose the correct passive sentence.)

a

A letter had been written by Veena

b

A letter is wrote by Veena

c

A letter was written by Veena

d

Write a letter by Veena

✓ Correct answer: a)

A letter had been written by Veena

Explanation

Active sentence: Veena had written a letter.

Tense: Past Perfect Tense (had written).

Rule for passive voice (Past Perfect Tense):

Object + had been + past participle (V³) + by + subject

Here,

  • Object → a letter

  • Verb → had been written

  • Subject → by Veena

So, the correct passive sentence is: A letter had been written by Veena.

The other options are incorrect because:

  • B. A letter is wrote by Veena - Incorrect tense ('is' = present) and wrong verb form ('wrote' instead of 'written').
  • C. A letter was written by Veena - This is simple past passive, not past perfect passive
  • D. Write a letter by Veena - Imperative form; not a passive sentence.
