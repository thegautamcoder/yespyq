Q1

Derivative of cosx is :

a

-sinx2x

b

sinx2x

c

2xcosx

d

2xsinx

🔒

✓ Correct answer: a)

-sinx2x

Explanation

 We need to differentiate  cos(x)  with respect to x. 

Step 1: Apply Chain Rule

Let: y=cosx

 Define u=x⇒x1/2, so that:                                                        y=cosu

Now, differentiate both sides:

dydx=dducos(u)⋅dudx

Step 2: Compute the Derivatives

d(cosu)du=-sin(u)dudx=d x(12)dx


Step 3: Multiply the Terms

dydx=-sinx2x

Q2

The function \(f(x)=x^3-3 x^2+12 x-18\) is :

a

strictly decreasing on \(R\)

b

strictly increasing on \(R\)

c

neither strictly increasing nor strictly decreasing on \(R\)

d

strictly decreasing on \((-\infty, 0)\)

🔒

✓ Correct answer: b)

Explanation

Q4

The function f(x)=x2+2x has a local minima at x equal to :

a

2

b

1

c

0

d

-2

🔒
Answer & explanation — PYQ Pass

Unlock · ₹149
✓ Correct answer: a)

2

Explanation

f(x)=x2+2x

f'(x)=ddx12x+2x-1=12-2x-2=12-2x2

Critical points occur where the first derivative is equal to zero.

12-2x2=012-2x2=0x2=4x=±2

Find the second derivative.

f''(x)=ddx12-2x-2=0-2(-2)x-3=4x3

f''2=423=48=12, since f''(2)>0 there is a local minima at x=2.

f''-2=4-23=4-8=-12, since f''(-2)<0,there is a local maxima at x=-2.

Q11

Let \(f(x)\) be a continuous function on \([a, b]\) and differentiable on \((a, b)\). Then, this function \(f(x)\) is strictly increasing in \((a, b)\) if

a

f'(x)<0,∀x∈(a,b)

b

f'(x)>0,∀x∈(a,b)

c

f'(x)=0,∀x∈(a,b)

d

f(x)=0,∀x∈(a,b)

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: b)

f'(x)>0,∀x∈(a,b)

Explanation

A function \(f(x)\) is strictly increasing on an interval \((a, b)\) if for any two points \(x_1, x_2 \in(a, b)\), with \(x_1<x_2\), we have \(f\left(x_1\right)<f\left(x_2\right)\). This means that the derivative of the function, \(f^{\prime}(x)\), must be positive for all \(x\) in ( \(a, b\) ). Therefore, the correct condition for \(f(x)\) to be strictly increasing in \((a, b)\) is \(f^{\prime}(x)>0\) for all \(x\) in \((a, b)\).

Q13

Let \(f(x)\) be a continuous function on \([a, b]\) and differentiable on \((a, b)\). Then, this function \(f(x)\) is strictly increasing in \((a, b)\) if

a

\(\mathrm{f}^{\prime}(\mathrm{x})<0, \forall \mathrm{x} \in(\mathrm{a}, \mathrm{b})\)

b

\(\mathrm{f}^{\prime}(\mathrm{x})>0, \forall \mathrm{x} \in(\mathrm{a}, \mathrm{b})\)

c

\(\mathrm{f}^{\prime}(\mathrm{x})=0, \forall \mathrm{x} \in(\mathrm{a}, \mathrm{b})\)

d

\(\mathrm{f}(\mathrm{x})>0, \forall \mathrm{x} \in(\mathrm{a}, \mathrm{b})\)

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: b)

\(\mathrm{f}^{\prime}(\mathrm{x})>0, \forall \mathrm{x} \in(\mathrm{a}, \mathrm{b})\)

Explanation

Let \(x_1<x_2 \in(a, b)\).
By MVT, there exists \(\ c\) in \(\left(x_1, x_2\right)\) with \(\frac{f\left(x_2\right)-f\left(x_1\right)}{x_2-x_1}=f^{\prime}(c)\).
Assume \(f^{\prime}(x)>0 \ \forall x \in(a, b)\).
Then \(f^{\prime}(c)>0\) and \(x_2-x_1>0\).
\(\Rightarrow f\left(x_2\right)-f\left(x_1\right)>0\).
\(\Rightarrow f\left(x_2\right)>f\left(x_1\right)\) (strictly increasing).
