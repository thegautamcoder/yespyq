For which value of k, linear pair x+y-4=0,2x+ky-3=0 has no solution?

a

0

b

2

c

6

d

8

✓ Correct answer: b)

2

Explanation

The condition for no solution is a1a2=b1b2≠c1c2

Here, a1=1,b1=1,c1=-4 and a2=2,b2=k,c2=-3

Applying the condition:
12=1k

Cross-multiplying gives:
k=2

Check the second part:

1k≠-4-3

For k=2, this is 12≠43

which is true.

Therefore, the correct answer is (B).
