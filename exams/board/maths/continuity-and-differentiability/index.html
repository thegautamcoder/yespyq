Q2

Question. Number of points of discontinuity of the function
f(x)=1x−5,x≠5
is :

a

1

b

2

c

3

d

5

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

1

ExplanationStep 1: Check for Points of Discontinuity

A function is discontinuous at points where:

  1. It is not defined.
  2. The left-hand limit (LHL) and right-hand limit (RHL) do not match or are not finite.

The given function is undefined at x=5x = 5 as the denominator becomes zero, leading to an infinite discontinuity.

Step 2: Verify if There Are Other Discontinuities

The function is well-defined and continuous everywhere else because it is a simple rational function(except x=5)

Step 3: Conclusion

Since there is only one point where the function is not defined (x=5x = 5x=5), the number of points of discontinuity is 1.

The number of points of discontinuity of \(f(x)=\left\{\begin{aligned}|x|+3, & \text { if } x \leq-3 \\ -2 x, & \text { if }-3<x<3 \\ 6 x+2, & \text { if } x \geq 3\end{aligned}\right.\) is :

a

0

b

1

c

2

d

infinite

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: b)

1

Explanation

For \(x \leq-3: f(x)=|x|+3\)

⇒ continuous on \((-\infty,-3]\)

For \(-3<x<3\) : \(f(x)=-2 x\)

⇒ continuous on \((-3,3)\)

For \(x \geq 3: f(x)=6 x+2\)

⇒ continuous on \([3, \infty)\)

At \(x=-3: \lim _{x \rightarrow(-3)^{-}}(|x|+3)=|-3|+3=6\)

\(\lim _{x \rightarrow(-3)^{+}}(-2 x)=-2(-3)=6\)

⇒ continuous at \(x=-3\)

At \(x=3: \lim _{x \rightarrow 3^{-}}(-2 x)=-2(3)=-6\)

\(\lim _{x \rightarrow 3^{+}}(6 x+2)=6(3)+2=20\)

⇒ discontinuous at \(x=3\)

The number of points of discontinuity of \(f(x)=\left\{\begin{aligned}|x|+3, & \text { if } x \leq-3 \\ -2 x, & \text { if }-3<x<3 \\ 6 x+2, & \text { if } x \geq 3\end{aligned}\right.\) is :

a

0

b

1

c

2

d

infinite

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: b)

1

Explanation

For \(x \leq-3: f(x)=|x|+3\)

⇒ continuous on \((-\infty,-3]\)

For \(-3<x<3\) : \(f(x)=-2 x\)

⇒ continuous on \((-3,3)\)

For \(x \geq 3: f(x)=6 x+2\)

⇒ continuous on \([3, \infty)\)

At \(x=-3\):

L.H.L\(=\lim _{x \rightarrow(-3)^{-}}(|x|+3)=|-3|+3=6\)

R.H.L.\(=\lim _{x \rightarrow(-3)^{+}}(-2 x)=-2(-3)=6\)

\(f(-3)=6\)

\(\because\)L.H.L.\(=\)R.H.L.\(=f(-3)\)

⇒ continuous at \(x=-3\)

At \(x=3\):

L.H.L.\(=\lim _{x \rightarrow 3^{-}}(-2 x)=-2(3)=-6\)

R.H.L.\(=\lim _{x \rightarrow 3^{+}}(6 x+2)=6(3)+2=20\)

\(f(3)=20\)

\(\because\)L.H.L \(\neq\) R.H.L.\(=f(3)\)

⇒ discontinuous at \(x=3\)

Q13

Which of the following statements is true for the function \(f(x)=\left\{\begin{array}{cc}x^2+3, & x \neq 0 \\ 1, & x=0\end{array} ?\right.\)

a

\(\mathrm{f}(\mathrm{x})\) is continuous and differentiable \(\forall \mathrm{x} \in \mathbb{R}\)

b

\(\mathrm{f}(\mathrm{x})\) is continuous \(\forall \mathrm{x} \in \mathbb{R}\)

c

\(f(x)\) is continuous and differentiable \(\forall x \in \mathbb{R}-\{0\}\)

d

\(f(x)\) is discontinuous at infinitely many points

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: c)

\(f(x)\) is continuous and differentiable \(\forall x \in \mathbb{R}-\{0\}\)

Explanation

Given: \(f(x)=\left\{\begin{array}{cc}x^2+3, & x \neq 0 \\ 1, & x=0\end{array}\right.\)

Now, \(f(0)=1 \text {. }\)
\(\lim _{x \rightarrow 0} f(x)=\lim _{x \rightarrow 0}\left(x^2+3\right)=3\)
Since \(\lim _{x \rightarrow 0} f(x) \neq f(0), f(x) \) is not continuous at \(x=0 \).

For \(x \neq 0, f(x)=x^2+3\) which is a polynomial and hence continuous everywhere except at \(x=0\).

For \(x \neq 0, f(x)=x^2+3\) is differentiable since it is a polynomial.
At \(x=0\), since \(f(x)\) is not continuous, it cannot be differentiable.

Therefore \(f\) is continuous and differentiable on \(\mathbb{R} - \{0\}\).
