Q1

A problem is given to three students A,B and C, whose probabilities of solving the problem independently are 12,34 and p respectively. If the probability that the problem can be solved is 2932, then what is the value of p?

a

25

b

23

c

13

d

14

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: d)

14

Explanation

Given that, P(A)=12,P(B)=34 and P(C)=p
Probability that the problem can not be solved

=P(A¯)⋅P(B¯)⋅P(C¯)

=1−121−34(1−p)

=12×14(1−p)=1−p8

∴ Probability that the problem can be solved

=1-Probability that the problem cannot be solved

⇒2932=1−(1−p)8

⇒1−p=34

∴p=14

Q2

If \(A\) and \(B\) are events such that P(A/B)=P(B/A)≠0, then :

a

A⊂B, but A≠B

b

A=B

c

A∩B=ϕ

d

P(A)=P(B)

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: d)

P(A)=P(B)

Explanation

We know that, PA∣B=P(A∩B)P(B),

PB∣A=P(A∩B)P(A)

Now,

PA∣B=PB∣A⇒P(A∩B)P(B)=P(A∩B)P(A)

Since PA∣B≠0⇒PA∩B≠0.

Therefore,

PA∩B·PA=PA∩B·PB⇒PA=PB

P(E¯)P(F¯)

1-P(E¯/F)

1-P(E/F)

1-P(E∪F)P(F¯)

Q5

If A and B are events such that P(A/B)=P(B/A)≠0, then :

a

A⊂B, but A≠B

b

A=B

c

A∩B=ϕ

d

P(A)=P(B)

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: d)

P(A)=P(B)

Explanation

P(A∣B)=P(A∩B)P(B)

P(B∣A)=P(A∩B)P(A)

Now,

P(A∣B)=P(B∣A)P(A∩B)P(B)=P(A∩B)P(A)

Therefore,

P(A∩B)·P(A)=P(A∩B)·P(B)P(A)=P(B)

Q7

If \(\mathrm{P}(\mathrm{A} \mid \mathrm{B})=\mathrm{P}\left(\mathrm{A}^{\prime} \mid \mathrm{B}\right)\), then which of the following statements is true?

a

\(\quad \mathrm{P}(\mathrm{A})=\mathrm{P}\left(\mathrm{A}^{\prime}\right)\)

b

\(\quad \mathrm{P}(\mathrm{A})=2 \mathrm{P}(\mathrm{B})\)

c

\(\quad \mathrm{P}(\mathrm{A} \cap \mathrm{B})=\frac{1}{2} \mathrm{P}(\mathrm{B})\)

d

\(\quad \mathrm{P}(\mathrm{A} \cap \mathrm{B})=2 \mathrm{P}(\mathrm{B})\)

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: c)

\(\quad \mathrm{P}(\mathrm{A} \cap \mathrm{B})=\frac{1}{2} \mathrm{P}(\mathrm{B})\)

Explanation

\(P(A \mid B)=P\left(A^{\prime} \mid B\right)\)

\(\frac{P(A \cap B)}{P(B)}=\frac{P\left(A^{\prime} \cap B\right)}{P(B)}\)

\(P(A \cap B)=P\left(A^{\prime} \cap B\right)\)

\(P(A \cap B)=P(B)-P(A \cap B)\)

\(2 P(A \cap B)=P(B)\)

\(\Rightarrow P(A \cap B)=\frac{1}{2} P(B)\)

Q8

Bag A contains 2 white, 1 black and 3 red balls and bag B contains 3 black, 2 red and n white balls. One bag is chosen at random and 2 balls drawn from it at random are found to be 1 red and 1 black. If the probability that both balls come from Bag A is 611, then n is equal to_______.

[JEE Main 2022, 24 Jun (Shift 1)]

a

13

b

6

c

4

d

3

✓ Correct answer: c)

4

Explanation

\(\begin{aligned} & \text { (c) } E _1=\text { denotes selection for } 1^{\text {st }} \text { bag } \\ & E _2=\text { denotes selection for } 2^{\text {st }} \text { bag } \\ & P \left( E _1\right)=\frac{1}{2}, P \left( E _2\right)=\frac{1}{2} \\ & A =\text { selected balls are } 1 \text { red \& } 1 \text { black } \\ & P\left(\frac{A}{E_1}\right)=\frac{{ }^3 C_1 \times C_1}{{ }^6 C_2}=\frac{1}{5} \\ & P\left(\frac{A}{E_2}\right)=\frac{{ }^3 C_1 \times{ }^2 C_1}{(n+5) C_2}=\frac{12}{(n+5)(n+4)} \\ & P\left(\frac{E_1}{A}\right)=\frac{P\left(E_1\right) \times P\left(\frac{A}{E_1}\right)}{P\left(E_1\right) \times P\left(\frac{A}{E_1}\right)+P\left(E_2\right) \times P\left(\frac{A}{E_2}\right)} \\ & =\frac{1}{\frac{1}{10}+\frac{6}{(n+5)(n+4)}}=\frac{6}{11} \\ & \Rightarrow n=4\end{aligned}\)
