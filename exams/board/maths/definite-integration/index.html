Q1

\(\int_a^b f(x) d x\) is equal to :

a

\(\int_a^b f(a-x) d x\)

b

\(\int_a^b f(a+b-x) d x\)

c

\(\int_{\mathrm{a}}^{\mathrm{b}} \mathrm{f}(\mathrm{x}-(\mathrm{a}+\mathrm{b})) \mathrm{dx}\)

d

\(\int_{\mathrm{a}}^{\mathrm{b}} \mathrm{f}((\mathrm{a}-\mathrm{x})+(\mathrm{b}-\mathrm{x})) \mathrm{dx}\)

🔒

✓ Correct answer: b)

\(\int_a^b f(a+b-x) d x\)

Explanation

Let \(x=a+b-u\).

dx=-du . 

When \(x=a, u=b\);

when \(x=b, u=a\).

∫abfxdx=∫u=bu=afa+b-u-du

⇒∫abfxdx=∫u=au=bfa+b-udu

Rename \(u\) to \(x\) :

\(\int_a^b f(x) d x=\int_a^b f(a+b-x) d x\).

f(x)<0 only for x∈[−1,  3)

✓ Correct answer: b)

f(x)<0 only for x∈[−1,  3)

Explanation

\(f(x)=[x]^2-[x]-6=([x]+2)([x]-3)\)

\(f(x)=0 \Rightarrow[x]=3\) or \([x]=-2\)

Infinitely many solutions.

\(f(x)>0 \Rightarrow[x] \in(-\infty,-2) \cup(3, \infty)\)

\(\Rightarrow x \in(-\infty,-2) \cup[4, \infty)\)

\(f(x)<0 \Rightarrow[x] \in(-2,3)\)

\(\Rightarrow x \in[-1,3)\)

\(\int_0^2 f(x) d x=\int_0^1(0-0-6) d x+\int_1^2(1-1-6) d x\)

\(=-6-6 =-12\)

✓ Correct answer: d)

Explanation

\( I=\int_{\frac{\pi}{24}}^{\frac{5 \pi}{24}} \frac{d x}{1+\sqrt[3]{\tan 2 x}} \)

\(I=\int_{\frac{\pi}{24}}^{\frac{5 \pi}{24}} \frac{\cos ^{1 / 3} 2 x}{\sin ^{1 / 3} 2 x+\cos ^{1 / 3} 2 x} d x \ldots (1)\)

Using king rule :

\(I=\int_{\frac{\pi}{24}}^{\frac{5 \pi}{24}} \frac{\sin ^{1 / 3} 2 x}{\cos ^{1 / 3} 2 x+\sin ^{1 / 3} 2 x} \ldots (2)\)

adding (1) and (2), we get

\(2 I=\frac{5 \pi}{24}-\frac{\pi}{24}=\frac{\pi}{6} \)

\(I=\frac{\pi}{12}\)

Q11

If f(2a-x)=f(x) , then∫02af(x)dx is

a

∫02afx2dx

b

∫0af(x)dx

c

2∫a0f(x)dx

d

2∫0af(x)dx

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: d)

2∫0af(x)dx

Explanation

Let \(I=\int_0^{2 a} f(x) d x\)

\(I=\int_0^a f(x) d x+\int_a^{2 a} f(x) d x\)

In \(\int_a^{2 a} f(x) d x\), put \(x=2 a-t, d x=-d t\)

\(\int_a^{2 a} f(x) d x=\int_a^0 f(2 a-t)(-d t)=\int_0^a f(2 a-t) d t\)

Given \(f(2 a-t)=f(t)\)

\(\Rightarrow \int_a^{2 a} f(x) d x=\int_0^a f(t) d t\)

\(\Rightarrow I=\int_0^a f(x) d x+\int_0^a f(x) d x=2 \int_0^a f(x) d x\)

✓ Correct answer: d)

2∫0af(x)dx

Explanation

Let \(I=\int_0^{2 a} f(x) d x\)

Using the property of breaking the limits :

\(I=\int_0^a f(x) d x+\int_a^{2 a} f(x) d x\)

In \(\int_a^{2 a} f(x) d x\), put \(x=2 a-t, d x=-d t\)

\(\int_a^{2 a} f(x) d x=\int_a^0 f(2 a-t)(-d t)=\int_0^a f(2 a-t) d t\)

Given \(f(2 a-t)=f(t)\)

\(\Rightarrow \int_a^{2 a} f(x) d x=\int_0^a f(t) d t\)

Now, using the property of changing the variable :

\(\Rightarrow I=\int_0^a f(x) d x+\int_0^a f(x) d x=2 \int_0^a f(x) d x\)
