Q1

Let π2<x<π be such that cotx=-511. Then sin11x2(sin6x-cos6x)+cos11x2(sin6x+cos6x) is equal to

a

11-123

b

11+123

c

11+132

d

11-132

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: b)

11+123

Explanation

  1. Simplify the trigonometric expression

Let the given expression be EE.

E=(sin⁡11x2)(sin⁡6x−cos⁡6x)+(cos⁡11x2)(sin⁡6x+cos⁡6x)E = \left(\sin \frac{11x}{2}\right)(\sin 6x - \cos 6x) + \left(\cos \frac{11x}{2}\right)(\sin 6x + \cos 6x)

Expand the terms:

E=sin⁡11x2sin⁡6x−sin⁡11x2cos⁡6x+cos⁡11x2sin⁡6x+cos⁡11x2cos⁡6xE = \sin \frac{11x}{2} \sin 6x - \sin \frac{11x}{2} \cos 6x + \cos \frac{11x}{2} \sin 6x + \cos \frac{11x}{2} \cos 6x

Rearrange the terms to group familiar identities:

E=(cos⁡11x2cos⁡6x+sin⁡11x2sin⁡6x)+(cos⁡11x2sin⁡6x−sin⁡11x2cos⁡6x)E = \left(\cos \frac{11x}{2} \cos 6x + \sin \frac{11x}{2} \sin 6x\right) + \left(\cos \frac{11x}{2} \sin 6x - \sin \frac{11x}{2} \cos 6x\right)

We recognize the cosine difference formula

cos⁡(A−B)=cos⁡Acos⁡B+sin⁡Asin⁡B\cos(A-B) = \cos A \cos B + \sin A \sin B and

the sine difference formula

sin⁡(B−A)=sin⁡Bcos⁡A−cos⁡Bsin⁡A\sin(B-A) = \sin B \cos A - \cos B \sin A.

Let A=11x2A = \frac{11x}{2} and B=6xB = 6x.

The first part is cos⁡(11x2−6x)\cos\left(\frac{11x}{2} - 6x\right).

The second part is sin⁡(6x−11x2)\sin\left(6x - \frac{11x}{2}\right).

Calculate the arguments:

A−B=11x2−12x2=−x2A - B = \frac{11x}{2} - \frac{12x}{2} = -\frac{x}{2}

B−A=12x2−11x2=x2B - A = \frac{12x}{2} - \frac{11x}{2} = \frac{x}{2}

Substitute these back into the expression:

E=cos⁡(−x2)+sin⁡(x2)E = \cos\left(-\frac{x}{2}\right) + \sin\left(\frac{x}{2}\right)

Since cosine is an even function

, cos⁡(−θ)=cos⁡(θ)\cos(-\theta) = \cos(\theta):

E=cos⁡(x2)+sin⁡(x2)E = \cos\left(\frac{x}{2}\right) + \sin\left(\frac{x}{2}\right)

  1. Determine sin⁡x\sin x and cos⁡x\cos x from the given cot⁡x\cot x

We are given cot⁡x=−511\cot x = -\frac{5}{\sqrt{11}} and π2<x<π\frac{\pi}{2} < x < \pi.

The condition π2<x<π\frac{\pi}{2} < x < \pi means xx is

in the second quadrant. In the second quadrant,

sin⁡x>0\sin x > 0 and cos⁡x<0\cos x < 0.

We can construct a right triangle where

the adjacent side is 5 and the opposite

side is 11\sqrt{11} (ignoring the sign for now).

The hypotenuse hh is calculated

using the Pythagorean theorem:

h=52+(11)2=25+11=36=6h = \sqrt{5^2 + (\sqrt{11})^2} = \sqrt{25 + 11} = \sqrt{36} = 6

Now, we can find sin⁡x\sin x and cos⁡x\cos x:

sin⁡x=oppositehypotenuse=116\sin x = \frac{\text{opposite}}{\text{hypotenuse}} = \frac{\sqrt{11}}{6}

cos⁡x=adjacenthypotenuse=56\cos x = \frac{\text{adjacent}}{\text{hypotenuse}} = \frac{5}{6}

Applying the signs for the second quadrant:

sin⁡x=116\sin x = \frac{\sqrt{11}}{6}

cos⁡x=−56\cos x = -\frac{5}{6}

  1. Determine sin⁡(x2)\sin\left(\frac{x}{2}\right) and cos⁡(x2)\cos\left(\frac{x}{2}\right)

Given π2<x<π\frac{\pi}{2} < x < \pi, we can find the range for x2\frac{x}{2}:

π4<x2<π2\frac{\pi}{4} < \frac{x}{2} < \frac{\pi}{2}

This means x2\frac{x}{2} is in the first quadrant.

In the first quadrant, both sin⁡(x2)\sin\left(\frac{x}{2}\right) and

cos⁡(x2)\cos\left(\frac{x}{2}\right) are positive.

We use the half-angle formulas:

sin⁡2(x2)=1−cos⁡x2\sin^2\left(\frac{x}{2}\right) = \frac{1 - \cos x}{2}

cos⁡2(x2)=1+cos⁡x2\cos^2\left(\frac{x}{2}\right) = \frac{1 + \cos x}{2}

Substitute the value of cos⁡x=−56\cos x = -\frac{5}{6}:

sin⁡2(x2)=1−(−56)2=1+562=6+562=1162=1112\sin^2\left(\frac{x}{2}\right) = \frac{1 - \left(-\frac{5}{6}\right)}{2} = \frac{1 + \frac{5}{6}}{2} = \frac{\frac{6+5}{6}}{2} = \frac{\frac{11}{6}}{2} = \frac{11}{12}

Since sin⁡(x2)>0\sin\left(\frac{x}{2}\right) > 0:

sin⁡(x2)=1112=114⋅3=1123\sin\left(\frac{x}{2}\right) = \sqrt{\frac{11}{12}} = \frac{\sqrt{11}}{\sqrt{4 \cdot 3}} = \frac{\sqrt{11}}{2\sqrt{3}}

And for cos⁡(x2)\cos\left(\frac{x}{2}\right):

cos⁡2(x2)=1+(−56)2=1−562=6−562=162=112\cos^2\left(\frac{x}{2}\right) = \frac{1 + \left(-\frac{5}{6}\right)}{2} = \frac{1 - \frac{5}{6}}{2} = \frac{\frac{6-5}{6}}{2} = \frac{\frac{1}{6}}{2} = \frac{1}{12}

Since cos⁡(x2)>0\cos\left(\frac{x}{2}\right) > 0:

cos⁡(x2)=112=14⋅3=123\cos\left(\frac{x}{2}\right) = \sqrt{\frac{1}{12}} = \frac{1}{\sqrt{4 \cdot 3}} = \frac{1}{2\sqrt{3}}

  1. Calculate the final expression

Now substitute the values of sin⁡(x2)\sin\left(\frac{x}{2}\right) and cos⁡(x2)\cos\left(\frac{x}{2}\right)

into the simplified expression EE:

E=cos⁡(x2)+sin⁡(x2)E = \cos\left(\frac{x}{2}\right) + \sin\left(\frac{x}{2}\right)

E=123+1123E = \frac{1}{2\sqrt{3}} + \frac{\sqrt{11}}{2\sqrt{3}}

E=1+1123E = \frac{1 + \sqrt{11}}{2\sqrt{3}}

Comparing this result with the given options:

A: 11−123\frac{\sqrt{11}-1}{2\sqrt{3}}

B: 11+123\frac{\sqrt{11}+1}{2\sqrt{3}}

C: 11+132\frac{\sqrt{11}+1}{3\sqrt{2}}

D: 11−132\frac{\sqrt{11}-1}{3\sqrt{2}}

The calculated value matches option B.

The final answer is B 11+123\boxed{\text{B } \frac{\sqrt{11}+1}{2\sqrt{3}}}.
