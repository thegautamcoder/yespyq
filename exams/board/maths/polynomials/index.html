Q1 FREE PREVIEW

If twice the first number x is 5 less than 7 times

the second number y,

then which of the following equations is correct?

a

\(2x=7y+5\)

b

\(5x=7y+2\)

c

\(7x=2y-5\)

d

\(2x=7y-5\)

✓ Correct answer: d)

\(2x=7y-5\)

Explanation

let translate the statement into equation

Twice the first number x” →2x
5 less than 7 times the second number y” → \(7y−5\)

According to the statement:

\(2x=7y−5\)

This is the correct equation.
