Q1 FREE PREVIEW

Match List-I with List-II:

List-I List-II
(A) Meghe Dhaka Tara (I) Govind Nihalani
(B) Garam Hawa (II) Habib Tanvir
(C) Tamas (III) Ritwik Ghatak
(D) Jis Lahore Nahin Vekhya O Jamya-e-nai (IV) M.S. Sathyu

Choose the correct answer from the options given below:

a

(A) - (IV), (B) - (III), (C) - (II), (D) - (I)

b

(A) - (III), (B) - (IV), (C) - (I), (D) - (II)

c

(A) - (II), (B) - (I), (C) - (IV), (D) - (III)

d

(A) - (III), (B) - (IV), (C) - (I), (D) - (II)

✓ Correct answer: b)

(A) - (III), (B) - (IV), (C) - (I), (D) - (II)

Explanation

Answer:

(A) "Meghe Dhaka Tara" was directed by Ritwik Ghatak, so it matches with (III).
(B) "Garam Hawa" was directed by M.S. Sathyu, so it matches with (IV).
(C) "Tamas" was directed by Govind Nihalani, so it matches with (I).
(D) "Jis Lahore Nahin Vekhya O Jamya-e-nai" is a play associated with Habib Tanvir, so it matches with (II).
The correct answer is (B) (A) - (III), (B) - (IV), (C) - (I), (D) - (II).
