Q1

Given below are two statements :
Statement I: In a vernier callipers, one vernier scale division is always smaller than one main scale division.
Statement II: The vernier constant is given by one main scale division multiplied by the number of vernier scale divisions.
In the light of the above statements, choose the correct answer from the options given below.

a

Statement I is false but Statement II is true

b

Statement I is true but Statement II is false

c

Both Statement I and Statement II are false

d

Both Statement I and Statement II are true

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: b)

Statement I is true but Statement II is false

Explanation

A vernier scale is designed such that its divisions are slightly smaller than the main scale divisions. This difference allows precise measurements by aligning a particular vernier division with the main scale.
The vernier constant (least count) is actually given by:
Least Count = Value of One Main Scale Division-Value of One Vernier Scale Division
Thus, the correct option is: 2.

Q2

Find the dimensions of \(\frac{B}{\mu_0}\) (Shift I Memory Based)

a

[AL]

b

AL-1

c

[MAL]

d

MALT-1

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: b)

AL-1

Explanation

Magnetic field B :
The dimensional formula for B is derived from the Lorentz force law:

\(
F=q v B \quad \Rightarrow \quad B=\frac{F}{q v}
\)

1. Force (F) has the dimensional formula:

\(
[F]=\left[\mathrm{MLT}^{-2}\right]
\)

2. Charge (q) has the dimensional formula:

\(
[q]=[\mathrm{AT}]
\)

3. Velocity (v) has the dimensional formula:

\(
[v]=\left[\mathrm{LT}^{-1}\right]
\)


Thus, the dimensional formula for B is:

\(
[B]=\frac{\left[\mathrm{MLT}^{-2}\right]}{[\mathrm{AT}]\left[\mathrm{LT}^{-1}\right]}=\frac{[\mathrm{M}]\left[\mathrm{T}^{-2}\right]}{[\mathrm{A}]}=[\mathrm{M}]\left[\mathrm{A}^{-1}\right]\left[\mathrm{T}^{-2}\right]
\)


Magnetic permeability ( \(\mu_0\) ):
The dimensional formula of \(\mu_0\) is:

\(
\left[\mu_0\right]=[\mathrm{M}][\mathrm{L}]\left[\mathrm{T}^{-2}\right]\left[\mathrm{A}^{-2}\right]
\)


Dimensions of \(\frac{B}{\mu_0}\) :
Using the formula:

\(
\frac{B}{\mu_0}=\frac{[\mathrm{M}]\left[\mathrm{A}^{-1}\right]\left[\mathrm{T}^{-2}\right]}{[\mathrm{M}][\mathrm{L}]\left[\mathrm{T}^{-2}\right]\left[\mathrm{A}^{-2}\right]}
\)


Cancel the terms:

\(
\frac{B}{\mu_0}=[\mathrm{A}]\left[\mathrm{L}^{-1}\right]
\)

The displacement of a particle as a function of time is given by:x(t)=Asin⁡(t)+Bcos⁡2(t)+Ct2+Dx(t) = A\sin(t) + B\cos^2(t) + Ct^2 + D.

Find the dimension of ABCD\frac{ABC}{D}

(Shift I Memory Based)

a

L2

b

L2T−2

c

LT−2

d

L3T

Answer & explanation — Premium

✓ Correct answer: b)

L2T−2

Explanation

The displacement x(t)x(t) has the dimension [L][L]. Each term in the equation must also have the same dimension [L][L]:

  • Asin⁡(t)A\sin(t): sin⁡(t)\sin(t) is dimensionless, so AA has [L][L].
  • Bcos⁡2(t)B\cos^2(t): cos⁡2(t)\cos^2(t) is dimensionless, so BB has [L][L].
  • Ct2Ct^2: t2t^2 has dimensions [T2][T^2], so CC must have [LT−2][L T^{-2}].
  • DD: As part of the displacement, DD has [L][L].

Thus, the dimensions of ABCD\frac{ABC}{D}​ are:

[L]⋅[L]⋅[LT−2][L]=[L2T−2]\frac{[L] \cdot [L] \cdot [L T^{-2}]}{[L]} = [L^2 T^{-2}]

Therefore, the correct answer is (b)\mathbf{(b)}.

b

\(\left[ M L ^2 T ^{-2}\right]\)

Answer & explanation — Premium

✓ Correct answer: a)

Explanation

Q13

Which of the following pairs of physical quantities have the same dimensions?(Shift - I Memory Based)

a

Angular momentum and Planck's constant

b

Torque and moment of inertia

c

Impulse and surface tension

d

Momentum and work done

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

Angular momentum and Planck's constant

Explanation

We analyze the dimensions of each pair of physical quantities to determine which have the same dimensions.

Option A: Angular Momentum and Planck's Constant

  • Angular momentum (LL):

    L=mvr=mass×velocity×distanceL = mvr = \text{mass} \times \text{velocity} \times \text{distance} =[M][LT−1][L]=[ML2T−1]= [M] [LT^{-1}] [L] = [M L^2 T^{-1}]

  • Planck's constant (hh):
    Planck’s constant is defined in the equation:

    E=hfE = h f

    where EE is energy and ff is frequency.
    Since energy has dimension [ML2T−2][M L^2 T^{-2}] and frequency [T−1][T^{-1}], we get:

    [h]=[E][f]=[ML2T−2][T−1]=[ML2T−1][h] = \frac{[E]}{[f]} = \frac{[M L^2 T^{-2}]}{[T^{-1}]} = [M L^2 T^{-1}]

Both have the same dimensions: [ML2T−1][M L^2 T^{-1}].

Option B: Torque and Moment of Inertia

  • Torque (τ\tau):

    τ=r×F=[L]×[MLT−2]=[ML2T−2]\tau = r \times F = [L] \times [M L T^{-2}] = [M L^2 T^{-2}]

  • Moment of inertia (II):

    I=mr2=[M][L2]=[ML2]I = m r^2 = [M] [L^2] = [M L^2]

Different dimensions.

Option C: Impulse and Surface Tension

  • Impulse (JJ):

    J=Force×time=[MLT−2][T]=[MLT−1]J = \text{Force} \times \text{time} = [M L T^{-2}] [T] = [M L T^{-1}]

  • Surface tension (TT):

    T=ForceLength=[MLT−2][L]=[MT−2]T = \frac{\text{Force}}{\text{Length}} = \frac{[M L T^{-2}]}{[L]} = [M T^{-2}]

Different dimensions.

Option D: Momentum and Work Done

  • Momentum (pp):

    p=mv=[M][LT−1]=[MLT−1]p = m v = [M] [L T^{-1}] = [M L T^{-1}]

  • Work Done (WW):

    W=Force×Distance=[MLT−2][L]=[ML2T−2]W = \text{Force} \times \text{Distance} = [M L T^{-2}] [L] = [M L^2 T^{-2}]

Different dimensions.

Final Answer:

AAngular momentum and Planck’s constant\boxed{A} \quad \text{Angular momentum and Planck's constant}

Q14

A physical quantity QQ is given by:Q=ab4cdQ = \frac{a b^4}{c d}​.If the percentage errors in a,b,ca, b, c and dd are 2%, 1%, 2%, and 1% respectively, determine the percentage error in QQ.

(Shift - II Memory Based)

a

2%

b

5%

c

9%

d

6%

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: c)

9%

Explanation

We are given the equation:

Q=ab4cdQ = \frac{a b^4}{c d}​

To determine the percentage error QQ, we use the error propagation rule:

ΔQQ=Δaa+4Δbb+Δcc+Δdd\frac{\Delta Q}{Q} = \frac{\Delta a}{a} + 4 \frac{\Delta b}{b} + \frac{\Delta c}{c} + \frac{\Delta d}{d}​

Step 1: Substituting Given Errors
  • Percentage error in a = 2%
  • Percentage error in b = 1%
  • Percentage error in c = 2%
  • Percentage error in d = 1%

Now, substituting these values into the equation:

Percentage error in Q=2+4(1)+2+1\text{Percentage error in } Q = 2 + 4(1) + 2 + 1 =2+4+2+1=9%= 2 + 4 + 2 + 1 = 9\%

Final Answer:

C9%\boxed{C} \quad 9\%C​
