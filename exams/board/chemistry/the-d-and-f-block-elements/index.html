Consider the following element in in TI, Al, and Pb .The most stable oxidation states of elements with highest and lowest first Ionisation enthalpies, respectively are:

Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: b)

Explanation

The ionization energy depends upon the size and effective nuclear charge. when we move down the group I.E decreases and across the period the I.E increases.

'Spin only' magnetic moment is same for which of the following ions?

Q14

Consider ' n ' is the number of lone pair of electrons present in the equatorial position of the most stable structure of ClF3. The ions from the following with ' n ' number of unpaired electrons are
A. V3+
B. Ti3+
C. Cu2+
D. Ni2+
E. Ti2+

Choose the correct answer from the options given below:

[JEE Main 2025, 28 Jan (Shift 1)]

a

B and C Only

b

A and C Only

c

B and D Only

d

A, D and E Only

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: d)

A, D and E Only

Explanation

The molecular structure of chlorine trifluoride (ClF3 ) is T- , following the VSEPR theory.
• Central atom: Chlorine (Cl)
• Total valence electrons: 7 + (3 × 7) = 28
• Bonded pairs: 3 fluorine atoms
• Lone pairs on Cl: 2
• Most stable structure: Trigonal bipyramidal electron geometry
• Fluorine atoms occupy axial positions.
• Two lone pairs occupy equatorial positions.
V+3, Ni+2 and Ti+2 have 2 unpaired electrons each.

Consider the following oxides,

V2O3, V2O4 and V2O5

Change in oxidation state of vanadium when amphoteric oxide reacts with acids to form VO2+ is (Memory Based Question 28/Jan/25 Evening shift)

a

0

b

2

c

3

d

4

Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

0

Explanation

Among the given oxides, V₂O₅ (vanadium(V) oxide) is amphoteric. When it reacts with acids, it forms VO₂⁺ (dioxovanadium ion).

  • The oxidation state of vanadium in V₂O₅ is +5.

Q20

Consider the following reactions

K2Cr2O7→KOHA→H2SO4B+K2SO4

The products A and B respectively are

[JEE Main 2025, 23 Jan (Shift 2)]

a

K2CrO4 and K2Cr2O7

b

K2CrOH6 and Cr2O3

c

K2CrO4 and Cr2O3

d

K2CrO4 and CrO

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

K2CrO4 and K2Cr2O7

Explanation

The correct answer is: K₂CrO₄ and K₂Cr₂O₇.

Reaction explanation:

K₂Cr₂O₇ reacts with KOH to form K₂CrO₄ (A) in an alkaline medium.

K₂CrO₄ converts back to K₂Cr₂O₇ (B) in an acidic medium (H₂SO₄).
Thus, [A] = K₂CrO₄ and [B] = K₂Cr₂O₇.
