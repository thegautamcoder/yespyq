Q1 FREE PREVIEW

Methyl group attached to a positively charged carbon atom stabilizes the carbocation due to

[Re-NEET 2024]

a

- I inductive effect

b

electromeric effect

c

hyperconjugation

d

mesomeric effect

✓ Correct answer: c)

hyperconjugation

Explanation

A methyl group adjacent to a carbocation donates electron density via hyperconjugation (overlap of σ–C–H orbitals with the vacant p orbital) and

+ Inductive effect. This stabilizes the positively charged center.

Q3 FREE PREVIEW

The interaction between \(\pi\) bond and lone pair of electrons present on an adjacent atom is responsible for

[JEE Main 2024, 29 Jan (Shift 1)]

a

Resonance effect

b

Hyperconjugation

c

Inductive effect

d

Electromeric effect

✓ Correct answer: a)

Resonance effect

Explanation

Correct Option: A – Resonance effect

Explanation:

The resonance effect arises when there is a π bond (double bond) and a lone pair of electrons on an adjacent atom. This allows delocalization of electrons through overlapping p-orbitals, creating multiple contributing structures (resonating structures) for a molecule.

Example:

In phenol, the lone pair on oxygen interacts with the π electrons of the benzene ring, resulting in resonance.

So, the interaction between a π bond and a lone pair on an adjacent atom is characteristic of the resonance effect.
