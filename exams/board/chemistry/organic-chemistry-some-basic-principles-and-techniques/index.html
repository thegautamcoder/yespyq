Q3

The interaction between \(\pi\) bond and lone pair of electrons present on an adjacent atom is responsible for

[JEE Main 2024, 29 Jan (Shift 1)]

a

Resonance effect

b

Hyperconjugation

c

Inductive effect

d

Electromeric effect

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

Resonance effect

Explanation

Correct Option: A – Resonance effect

Explanation:

The resonance effect arises when there is a π bond (double bond) and a lone pair of electrons on an adjacent atom. This allows delocalization of electrons through overlapping p-orbitals, creating multiple contributing structures (resonating structures) for a molecule.

Example:

In phenol, the lone pair on oxygen interacts with the π electrons of the benzene ring, resulting in resonance.

So, the interaction between a π bond and a lone pair on an adjacent atom is characteristic of the resonance effect.

Q6

Mixture of 1 g each of chlorobenzene, aniline and benzoic acid is dissolved in 50 mL ethyl acetate and placed in a separating funnel, 5 M NaOH ( 30 mL ) was added in the same funnel. The funnel was shaken vigorously and then kept aside. The ethyl acetate layer in the funnel contains

[JEE Main 2025, 7 Apr (Shift 2)]

a

benzoic acid

b

benzoic acid and aniline

c

benzoic acid and chlorobenzene

d

chlorobenzene and aniline

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: d)

chlorobenzene and aniline

Explanation

  • Benzoic acid (C₆H₅COOH) is acidic → it reacts with NaOH to form sodium benzoate (C₆H₅COO⁻ Na⁺), an ionic, water-soluble salt → it moves to the aqueous layer.

Q8

The interaction between π bond and lone pair of electrons present on an adjacent atom is responsible for:

a

Electromeric effect

b

Hyperconjugation

c

Inductive effect

d

Resonance effect

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: d)

Resonance effect

Explanation

The resonance effect (also called mesomeric effect) arises due to the interaction between a π bond and a lone pair of electrons (or another π bond) on an adjacent atom. This interaction allows electrons to be delocalized, creating multiple contributing structures (resonance structures) that help stabilize the molecule.

Examples:

  • In phenol, the lone pair on the oxygen interacts with the π electrons of the benzene ring.

  • In carboxylate ion (COO⁻), the lone pair on one oxygen is delocalized through resonance with the C=O π bond.
