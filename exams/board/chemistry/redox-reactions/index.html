Q3

Which reaction is NOT a redox reaction?

[NEET 2024]

a

BaCl2+Na2SO4→BaSO4+2NaCl

b

Zn+CuSO4→ZnSO4+Cu

c

2KClO3+I2→2KIO3+Cl2

d

H2+Cl2→2HCl

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

BaCl2+Na2SO4→BaSO4+2NaCl

Explanation

BaCl₂ + Na₂SO₄ → BaSO₄ + 2NaCl is a double displacement reaction with no change in oxidation states, so it is not a redox reaction. In the other options, there is a clear change in oxidation numbers indicating redox processes.

Q4

Which of the following does not show disproportionation reaction? (memory based jee mains shift-2 22/01/2025)

a

ClO-

b

ClO2-

c

ClO3-

d

ClO4-

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: d)

ClO4-

Explanation

ClO4- → chlorine is in its highest oxidation state i.e., +7.
Chlorine can exhibit a –1 to +7 oxidation state.
The oxidation states of chlorine which can undergo disproportionation are : 0, +1, +3, and +5.

Q5

Which of the following cannot function as an oxidising agent?

a

N3−

b

SO42−

c

BrO3−

d

MnO4−

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

N3−

Explanation

Oxidising agent wahi ban sakta hai jo khud reduce ho sake. N³⁻ me nitrogen ki oxidation state −3 hoti hai jo minimum hoti hai, aur ye aur reduce nahi ho sakta. Baaki ions (SO₄²⁻, BrO₃⁻, MnO₄⁻) me central atom ki high oxidation state hoti hai jo reduce ho sakti hai, isliye wo oxidising agent ho sakte hain.

Correct answer: N³⁻ cannot function as oxidising agent.

Q6

During the preparation of Mohr's salt solution (Ferrous ammonium sulphate), which of the following acid is added to prevent hydrolysis of Fe2+ ion?

[NEET 2024]

a

dilute sulphuric acid

b

dilute hydrochloric acid

c

concentrated sulphuric acid

d

dilute nitric acid

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

dilute sulphuric acid

Explanation

Mohr’s salt (ferrous ammonium sulphate) is commonly dissolved in slightly acidic solution (using dilute H₂SO₄) to prevent oxidation and hydrolysis of Fe²⁺ ions. The acidic medium suppresses Fe²⁺→Fe³⁺ conversion and formation of insoluble iron hydroxides, ensuring the stable, clear solution of Mohr’s salt.

Q8

Volume of M/8 KMnO4 solution required to react completely with 25.0 cm3 of M/4 FeSO4 in acidic medium is:

a

8.0 mL

b

5.0 mL

c

15.0 mL

d

10.0 mL

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: d)

10.0 mL

Explanation

The reaction is

MnO4- + 5Fe2+ + 8H+ → Mn2+ + 5Fe3+ + 4H₂O.

Using N₁V₁ = N₂V₂,

18×5V1=14×25

Solving, V₁ = 10 mL.
