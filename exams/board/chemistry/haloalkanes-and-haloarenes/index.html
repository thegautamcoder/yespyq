CH3-CH2-CH2-CH2-Cl→HO-CH3-CH2-CH2-CH2-OH+Cl(-)

CH3-CH2-CH2-CH2-Cl→R3N..CH3-CH2-CH2-CH2-N|(+)R|R-RCl(-)

In the light of the above statements, choose the correct answer from the options given below:

[JEE Main 2025, 24 Jan (Shift 1)]

a

Statement I is true but Statement II is false

b

Statement I is false but Statement II is true

c

d

Both Statement I and Statement II are true

Q6

The major product \(C\) in the below mentioned reaction is :
CH3CH2CH2Br→ΔAlc.KOHA→HBrB→∆Aq  KOHC

[Re-NEET 2024]

a

Propan-1-ol

b

Propan-2-ol

c

Propane

d

Propyne

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: b)

Propan-2-ol

Explanation

  1. CH₃CH₂CH₂Br + alc. KOH (∆) → propene (elimination)

  2. propene + HBr → 2‐bromopropane (Markovnikov addition)

  3. 2‐bromopropane + aq. KOH → 2‐propanol (nucleophilic substitution).
