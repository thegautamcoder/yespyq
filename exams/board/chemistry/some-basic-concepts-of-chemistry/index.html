Q1

The incorrect postulates of the Dalton's atomic theory are:

(A) Atoms of different elements differ in mass.

(B) Matter consists of divisible atoms.

(C) Compounds are formed when atoms of different element combine in a fixed ratio.

(D) All the atoms of given element have different properties including mass.

(E) Chemical reactions involve reorganisation of atoms.

Choose the correct answer from the options given below:

a

(B), (D), (E) only

b

(A), (B), (D) only

c

(C), (D), (E) only

d

(B), (D) only

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: d)

(B), (D) only

Explanation

(B) is incorrect because Dalton said atoms are indivisible, but subatomic particles exist.

(D) is wrong as Dalton assumed all atoms of an element are identical, but isotopes disprove this.

(E) is actually correct, as chemical reactions involve reorganization of atoms.

Hence, correct incorrect statements are only (B) and (D).

Q2

An organic compound has 42.1% carbon, 6.4% hydrogen and remainder is oxygen. If its molecular weight is 342, then its molecular formula is:

a

C11H18O12

b

C12H20O12

c

C14H20O10

d

C12H22O11

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: d)

C12H22O11

Explanation

Given:

C = 42.1%, H = 6.4%, O = 100 − 48.5 = 51.5%

Divide by atomic masses:

C → 42.1 ÷ 12 = 3.508

H → 6.4 ÷ 1 = 6.4

O → 51.5 ÷ 16 = 3.219

Divide all by 3.219:

C ≈ 1.09, H ≈ 1.99, O ≈ 1

Empirical formula ≈ C₁H₂O₁

Empirical mass = 12 + 2 + 16 = 30

n = 342 ÷ 30 = 11.4 ≈ 11

Molecular formula = C₁₁H₂₂O₁₁

Answer: Option D

Q5

The correct name of I & II in the following process is :

Solid →IVapours→IISolid
Memory Based Question 28/Jan/25 Evening shift

a

I →Sublimation

II →Vaporisation

b

I Sublimation

II Decomposition

c

I Sublimation

II Deposition

d

I Deposition

II Sublimation

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: c)

I Sublimation

II Deposition

Explanation

The given process represents phase transitions:

  • Solid → Vapors is sublimation (conversion of solid directly to gas).
  • Vapors → Solid is deposition (direct conversion of gas to solid).

Thus, the correct answer is:

(C) I → Sublimation, II → Deposition.

Q6

Choose the Incorrect Statement about Dalton's Atomic Theory

a

Compounds are formed when atoms of different elements combine in any ratio

b

All the atoms of a given element have identical properties including identical mass

c

Matter consists of indivisible atoms

d

Chemical reactions involve reorganization of atoms

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

Compounds are formed when atoms of different elements combine in any ratio

Explanation

Correct answer is A. Dalton’s atomic theory states that compounds form when atoms combine in a fixed simple whole number ratio, not any ratio. So option A is incorrect. Option B matches Dalton’s postulate, though it is now known isotopes exist. Option C is Dalton’s idea; although atoms are divisible (electrons, protons exist), this was Dalton’s belief. Option D is also correct per Dalton—he proposed that chemical reactions are rearrangements of atoms. Thus, option A contradicts Dalton’s theory and is the only incorrect statement among the given choices.
