Q3

Arrange the following taxonomic categories in ascending order.

(a) Genus

(b) Class

(c) Order

(d) Phylum

(e) Family

(f) Kingdom

(g) Species

Choose the correct answer from the options given below:

[Re-NEET 2026]

a

(g), (a), (e), (c), (b), (d), (f)

b

(a), (c), (d), (g), (f), (b), (e)

c

(g), (c), (d), (b), (e), (a), (f)

d

(f), (c), (b), (g), (d), (e), (a)

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

(g), (a), (e), (c), (b), (d), (f)

Explanation

Ascending order means arranging taxonomic categories from lowest to highest hierarchical rank. The standard classification hierarchy from lowest to highest is: Species → Genus → Family → Order → Class → Phylum → Kingdom.

Mapping the letters: (g) Species → (a) Genus → (e) Family → (c) Order → (b) Class → (d) Phylum → (f) Kingdom.

This translates to the sequence: (g), (a), (e), (c), (b), (d), (f). Hence, option (A) is the correct answer.

Q4

Genus represents ________.

[Re-NEET 2026]

a

an individual plant or animal

b

a population of plants and animals

c

a group of closely related species

d

a group of closely related families

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: c)

a group of closely related species

Explanation

In biological classification, species having many similar characteristics are grouped together into a genus.

For example:

  • Panthera leo (lion)
  • Panthera tigris (tiger)

Both belong to the same genus Panthera because they are closely related species.

Therefore, Genus represents a group of closely related species.

Correct answer: C. a group of closely related species

Q5

Which one of the following statements is not true about the universal rules of binomial nomenclature?

[NEET 2026]

a

Both the words in a biological name, when handwritten are separately underlined or printed in italics.

b

The specific epithet in the biological name starts with a small letter.

c

The first word in the biological name represents the specific epithet, while the second component denotes the genus.

d

Biological names are generally in Latin.

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: c)

The first word in the biological name represents the specific epithet, while the second component denotes the genus.

Explanation

Binomial nomenclature rules: scientific names consist of two words—genus and specific epithet—written in a standard format

  • Option A: True → when handwritten, both words are underlined separately; when printed, they are in italics
  • Option B: True → the specific epithet begins with a small letter
  • Option C: Not true → the first word represents the genus, and the second word represents the specific epithet
  • Option D: True → biological names are generally in Latin or latinised

Thus, the incorrect statement is: The first word in the biological name represents the specific epithet, while the second component denotes the genus

Final Answer: Option C
