Phosphoric acid ionizes in three steps with their ionization constant values \({\mathrm{K}}_{{\mathrm{a}}_{1}},{\mathrm{K}}_{{\mathrm{a}}_{2}}\) and \({\mathrm{K}}_{{\mathrm{a}}_{3}}\), respectively, while K is the overall ionization constant. Which of the following statements are true?

A. \(\log K=\log {K}_{{a}_{1}}+\log {K}_{{a}_{2}}+\log {K}_{{a}_{3}}\)
B. \({\mathrm{H}}_{3}{\mathrm{PO}}_{4}\) is a stronger acid than \({\mathrm{H}}_{2}{\mathrm{PO}}_{4}^{-}\)and \({\mathrm{HPO}}_{4}^{2-}\)

\(\mathrm{C}.{\mathrm{K}}_{{\mathrm{a}}_{1}}>{\mathrm{K}}_{{\mathrm{a}}_{2}}>{\mathrm{K}}_{{\mathrm{a}}_{3}}\\ \mathrm{D}.{\mathrm{K}}_{{\mathrm{a}}_{1}}=\frac{{\mathrm{K}}_{{\mathrm{a}}_{3}}+{\mathrm{K}}_{{\mathrm{a}}_{2}}}{2}\)

Choose the correct answer from the options given below

[NEET 2025]

a

B, C and D only

b

A, B and C only

c

A and B only

d

A and C only

✓ Correct answer: b)

A, B and C only

Explanation

Statement A:
Total ionization constant
K = Ka1 × Ka2 × Ka3

Taking log on both sides:
log K = log Ka1 + log Ka2 + log Ka3

Statement A is correct

Statement B:
The first ionization of H3PO4 is the greatest, so it is a stronger acid than H2PO4- and HPO42-

Statement B is correct

Statement C:
For polyprotic acids:
Ka1 > Ka2 > Ka3

Because removal of each successive proton becomes more difficult

Statement C is correct

Statement D:
Ka1 = (Ka3 + Ka2) / 2

No such general relation exists

Statement D is incorrect
