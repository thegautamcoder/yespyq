Q6

'Spin only' magnetic moment is same for which of the following ions?

A. Ti3+B. Cr2+C. Mn2+D. Fe2+E. Sc3+

Choose the most appropriate answer from the options given below:

[NEET 2024]

a

A and D only

b

B and D only

c

A and E only

d

B and C only

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: b)

B and D only

Explanation

Ti3+:3d1n=1Cr2+:3d4n=4Mn2+:3d5n=5Fe2+:3d6n=4Sc3+:3d0n=0

The number of unpaired electron (n) in 3d orbital is same for Cr2+ and Fe2+. They will have the same spin-only magnetic moment.

μ =n(n+2)  =4(4+2) =24 =4.90 BM

Q8

Which of the following set of ions act as oxidising agents?

[Re-NEET 2024]

\(Ce ^{4+}\) and \(Tb ^{4+}\)

b

\(La ^{3+}\) and \(Lu ^{3+}\)

c

\(Eu ^{2+}\) and \(Yb ^{2+}\)

d

\(Eu ^{2+}\) and \(Tb ^{4+}\)

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

\(Ce ^{4+}\) and \(Tb ^{4+}\)

Explanation

Higher‐oxidation‐state lanthanide ions such as Ce4+ and Tb4+ readily get reduced to more stable Ln3+ states, making them oxidizing agents. The other listed ions are either already in their more stable +3 state (La3+, Lu3+) or not favored to act as oxidizers (Eu2+, Yb2+).

Q11

Which of the following pairs of ions will have same spin only magnetic moment values within the pair?
A. \(Zn ^{2+}, Ti ^{2+}\)
B. \(Cr ^{2+}, Fe ^{2+}\)
C. \(Ti ^{3+}, Cu ^{2+}\)
D. \(V ^{2+}, Cu ^{+}\)

Choose the correct answer from the options given below :

[Re-NEET 2024]

a

C and D only

b

A and D only

c

A and B only

d

B and C only

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: d)

B and C only

Explanation

The value of magnetic moment is calculated using the formula:

μ= n(n+ 2) B.M.

where n = number of unpaired electrons.

Zn2+: [Ar] 3d10 → n = 0 → μ = 0 BM

Ti2+: [Ar] 3d2 → n = 2 → μ = √8 ≈ 2.83 BM

Different values.

Cr2+: [Ar] 3d4 → n = 4 → μ = √24 ≈ 4.90 BM
Fe2+: [Ar] 3d6 → n = 4 → μ = √24 ≈ 4.90 BM
Same magnetic moment.

Ti3+: [Ar] 3d1 → n = 1 → μ = √3 ≈ 1.73 BM
Cu2+: [Ar] 3d9 → n = 1 → μ = √3 ≈ 1.73 BM
Same magnetic moment.

V2+: [Ar] 3d3 → n = 3 → μ = √15 ≈ 3.87 BM
Cu+: [Ar] 3d10 → n = 0 → μ = 0 BM
Different values.
