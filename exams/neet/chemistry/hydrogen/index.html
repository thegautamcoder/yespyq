Q1 FREE PREVIEW

(A) \(\mathrm{HOCl}+\mathrm{H}_{2} \mathrm{O}_{2} \longrightarrow \mathrm{H}_{3} \mathrm{O}++\mathrm{Cl}^{-}+\mathrm{O}_{2}\)

(B) \(\mathrm{I}_{2}+\mathrm{H}_{2} \mathrm{O}_{2}+2 \mathrm{OH}^{-} \longrightarrow 2 \mathrm{I}^{-}+2 \mathrm{H}_{2} \mathrm{O}+\mathrm{O}_{2}\)

Choose the correct option

[JEE Main 2021, 24 Feb (Shift 1)]

a

\(\mathrm{H}_{2} \mathrm{O}_{2}\) acts as oxidizing agent in equations (A) and (B)

b

\(\mathrm{H}_{2} \mathrm{O}_{2}\) act as oxidizing and reducing agent respectively in equations \((\mathrm{A})\) and \((\mathrm{B})\)

c

\(\mathrm{H}_{2} \mathrm{O}_{2}\) acts as reducing and oxidizing agent respectively in equations (A) and (B)

d

\(\mathrm{H}_{2} \mathrm{O}_{2}\) acts as reducing agent in equations (A) and (B)

✓ Correct answer: d)

\(\mathrm{H}_{2} \mathrm{O}_{2}\) acts as reducing agent in equations (A) and (B)

Explanation

(d) In both the given reactions, \(\mathrm{H}_{2} \mathrm{O}_{2}\) acts as reducing agent. In reaction \((\mathrm{A}), \quad \mathrm{HOCl} \longrightarrow\) Oxidizing agent \(\mathrm{H}_{2} \mathrm{O}_{2} \longrightarrow\) Reducing agent

In reaction (B), \(\quad \mathrm{I}_{2} \longrightarrow\) Oxidizing agent \(\mathrm{H}_{2} \mathrm{O}_{2} \longrightarrow\) Reducing agent
