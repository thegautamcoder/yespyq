Phosphoric acid ionizes in three steps with their ionization constant values Ka1, Ka2 and Ka3, respectively, while K is the overall ionization constant. Which of the following statements are true?

A. logK=logKa1+logKa2+logKa3
B. H3PO4 is a stronger acid than H2PO4-and HPO42-

C. Ka1>Ka2>Ka3D. Ka1=Ka3+Ka22

Choose the correct answer from the options given below

[NEET 2025]

a

B, C and D only

b

A, B and C only

c

A and B only

d

A and C only

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: b)

A, B and C only

Explanation

Statement A:
Total ionization constant
K = Ka1 × Ka2 × Ka3

Taking log on both sides:
log K = log Ka1 + log Ka2 + log Ka3

Statement A is correct

Statement B:
The first ionization of H3PO4 is the greatest, so it is a stronger acid than H2PO4- and HPO42-

Statement B is correct

Statement C:
For polyprotic acids:
Ka1 > Ka2 > Ka3

Because removal of each successive proton becomes more difficult

Statement C is correct

Statement D:
Ka1 = (Ka3 + Ka2) / 2

No such general relation exists

Statement D is incorrect

Consider the following reaction in a sealed vessel at equilibrium with concentrations of N2=3.0×10-3M,O2=4.2×10-3M and NO=2.8×10-3M.
2NO(g)⇌N2(g)+O2(g)

If 0.1 molL-1 of NO(g) is taken in a closed vessel, what will be degree of dissociation (α) of NO(g) at equilibrium?

a

0.717

b

0.00889

c

0.0889

d

0.8889

🔒

✓ Correct answer: a)

0.717

Explanation

First, determine the equilibrium constant from the given data:

Kc = [N2][O2][NO]2=(3.0×10-3)(4.2×10-3)(2.8×10-3)2≈1.61.

Next, start with 0.1 M NO and let 2z2z be the amount of NO that dissociates:

[NO]eq=0.1−2z,[N2]eq=z,[O2]eq=z.[NO]_{\text{eq}} = 0.1 - 2z,\quad [N_2]_{\text{eq}} = z,\quad [O_2]_{\text{eq}} = z.

Then

Kc=1.61=z×z(0.1−2z)2=z2(0.1−2z)2.K_c=1.61 = \frac{z \times z}{(0.1 - 2z)^2} = \frac{z^2}{(0.1 - 2z)^2}.

Solving yields z≈0.036z \approx 0.036.

Degree of dissociation α\alpha is the fraction of the initial NO reacting:

α=moles of NOusedinitial moles=2z0.1=2×0.0360.1=0.72 ≈0.717.

3A2+B2 ⇌2A3B,  K1A3B ⇌32A2+12B2,  K2

The relation between \(K _1\) and \(K _2\) is :

a

K12=2K2

K2=K12

c

K1=1K2

d

K2=1K1

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: d)

K2=1K1

Explanation
  • When a reaction is reversed, the new equilibrium constant is the inverse of the original.
  • When a reaction is multiplied by a factor n, the new equilibrium constant is the original raised to the power of n.

Q9

In which of the following equilibria, Kp and Kc are not equal?

[NEET 2024]

a

2BrCl(g)⇌Br2(g)+Cl2(g)

b

 PCl5(g)⇌PCl3(g)+Cl2(g)

c

 H2(g)+I2(g)⇌2HI(g)

d

CO(g)+H2O(g)⇌CO2(g)+H2(g)

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: b)

 PCl5(g)⇌PCl3(g)+Cl2(g)

Explanation

Kp=KcK_p = K_c only when the total moles of gaseous products = total moles of gaseous reactants (Δng=0).(\Delta n_g = 0).

  • 2 BrCl(g) → Br2(g)+Cl2(g):2\,\mathrm{BrCl(g)\,\to\,Br_2(g) + Cl_2(g):} 2 → 2 (Δn = 0), so Kp=Kc.K_p=K_c.
  • PCl5(g) → PCl3(g)+Cl2(g):\mathrm{PCl_5(g)\,\to\,PCl_3(g) + Cl_2(g):} 1 → 2 (Δn = +1), so Kp≠Kc.K_p\neq K_c.
  • H2(g)+I2(g) → 2HI(g):\mathrm{H_2(g) + I_2(g)\,\to\,2HI(g):} 2 → 2 (Δn = 0), so Kp=Kc.K_p=K_c.
  • CO(g)+H2O(g) → CO2(g)+H2(g):\mathrm{CO(g) + H_2O(g)\,\to\,CO_2(g) + H_2(g):} 2 → 2 (Δn = 0), so Kp=Kc.K_p=K_c.
