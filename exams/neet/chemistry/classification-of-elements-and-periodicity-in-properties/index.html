aBoron
bAluminium
cGermanium
dThallium
✓ Correct answer: a) Boron
ExplanationBoron has the highest ionisation enthalpy amongst the following.Ionisation enthalpy decreases down the group and increases across the period.
Q2 FREE PREVIEW
The IUPAC symbol for the element with atomic number 119 would be :
aUnh
bUun
cUne
dUue
✓ Correct answer: d) Uue
ExplanationThe element with atomic number 119 is not yet officially discovered, so it has a temporary systematic IUPAC name.According to IUPAC rules: 1 → un 1 → un 9 → en Combine them: un-un-en → Uue Symbol: Uue
