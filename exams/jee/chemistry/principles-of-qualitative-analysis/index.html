Q5

When MnO2 and H2SO4 is added to a salt (A), the greenish yellow gas liberated as salt (A) isEndFragment

[JEE Main 2024, 04 Apr (Shift 2)]

a

CaI2

b

NaBr

c

KNO3

d

NH4Cl

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: d)

NH4Cl

Explanation

The greenish-yellow gas is chlorine (Cl₂).

MnO₂ + H₂SO₄ (conc.) generates nascent oxidizing conditions and can oxidize chloride ions (Cl⁻) to chlorine gas.

Reaction: 2Cl⁻ → Cl₂ (greenish-yellow gas)

Among the options, only NH₄Cl contains chloride ions.

So, NH₄Cl → Cl⁻ → Cl₂ (gas formed)

Q8

During the detection of acidic radical present in a salt, a student gets a pale yellow precipitate soluble with difficulty in \(NH _4 OH\) solution when sodium carbonate extract was first acidified with dil. \(HNO _3\) and then \(AgNO _3\) solution was added. This indicates presence of

[JEE Main 2024, 06 Apr (Shift 2)]

a

\(Br ^{-}\)

b

\(Cl ^{-}\)

c

\(CO _3{ }^{2-}\)

d

\(I ^{-}\)

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

\(Br ^{-}\)

Explanation

The sodium carbonate extract is first acidified with dilute nitric acid (HNO₃).
This step removes interfering ions like carbonate (CO₃²⁻) and sulfite by converting them into gases (CO₂, SO₂).
Then silver nitrate (AgNO₃) is added to detect halide ions.

If halide ions are present, they form precipitates:

Cl⁻ + Ag⁺ → AgCl (white precipitate)
Br⁻ + Ag⁺ → AgBr (pale yellow precipitate)
I⁻ + Ag⁺ → AgI (deep yellow precipitate)

The question clearly says: Pale yellow precipitate

So: Not Cl⁻ (white), Not I⁻ (deep yellow)

This strongly indicates Br⁻

Confirmation using NH₄OH solubility:

AgCl → dissolves easily
AgBr → dissolves with difficulty (sparingly soluble)
AgI → does not dissolve at all

Given: Pale yellow precipitate, dissolves with difficulty in NH₄OH

Only AgBr satisfies both conditions.

The acidic radical present is: Bromide ion (Br⁻)
