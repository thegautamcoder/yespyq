Q11

Given below are two statements : one is labelled as Assertion (A) and the other is labelled as Reason (R)

Assertion (A): Haloalkanes react with \(KCN\) to form alkyl cyanides as the main product while with \(AgCN\) form isocyanide as the main product.
Reason (R): \(~KCN\) and \(AgCN\) both are highly ionic compounds.

In the light of the above statements, choose the most appropriate answer from the options given below

[JEE Main 2024, 1 Feb (Shift 1)]

a

(A) is correct but (R) is not correct

b

Both (A) and (R) are correct but (R) is not the correct explanation of (A)

c

(A) is not correct but (R) is correct

d

Answer & explanation — Premium

✓ Correct answer: a)

(A) is correct but (R) is not correct

Explanation

Assertion (A) is correct because KCN provides free cyanide ion (CN⁻), which attacks through carbon, giving alkyl cyanide. AgCN, however, is covalent and provides the nitrogen end for attack, leading to isocyanide.

Q12

3-Methylhex-2-ene on reaction with HBr in presence of peroxide forms an addition product (A). The number of possible stereoisomers for 'A' is ________.

[JEE Main 2024, 27 Jan (Shift 1)]

a

6

b

5

c

4

d

3

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: c)

4

Explanation
  • Substrate: 3-Methylhex-2-ene
  • Reaction: With HBr in presence of peroxide → anti-Markovnikov addition.
  • Br attaches to C2, H attaches to C3.
  • Product: 2-bromo-3-methylhexane.
  • The carbon at C2 becomes chiral (attached to Br, H, C1 chain, and C3 chain).
  • The double bond addition can occur from two possible orientations (syn/anti relative approach), giving rise to two chiral centers in the product.
  • Hence, total stereoisomers = 2ⁿ = 2² = 4.
Q13

Identify the correct set of reagents or reaction conditions 'X' and 'Y' in the following set of transformation
CH3−CH2−CH2−Br→X′Product→Y′CH3−CHBr−CH3

[JEE Main 2024, 4 Apr (Shift 1)]

a

X=conc.alc.NaOH,80°C,Y=Br2/CHCl3

b

X=dil.aq.NaOH,20°C,  Y=HBr/acetic acid

c

X=conc. alc.NaOH,80°C,Y=HBr/acetic acid

d

X=dil.aq.NaOH,20°C,  Y=Br2/CHCl3

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: c)

X=conc. alc.NaOH,80°C,Y=HBr/acetic acid

Explanation

Step 1: Identify reaction X

Starting compound: 1-bromopropane.

To convert it into propene, we need elimination (E2).

Reagent: conc. alc. NaOH, 80°C → elimination of HBr → gives propene (CH3–CH=CH2).

So, X = conc. alc. NaOH, 80°C.

Step 2: Identify reaction Y

Now we have propene (CH3–CH=CH2)..

To convert it into 2-bromopropane (CH3–CHBr–CH3), we need electrophilic addition of HBr.

Reagent: HBr in acetic acid → Markovnikov addition → Br attaches to middle carbon → product is CH3–CHBr–CH3).

So, Y = HBr/acetic acid.

Explanation

When alkyl halides react with KCN, the free cyanide ion (C⁻) attacks through carbon, giving alkyl cyanide (R–CN). When they react with AgCN, due to its covalent nature, the attack occurs through nitrogen, giving alkyl isocyanide (R–NC).

Q21

The correct statement regarding nucleophilic substitution reaction in a chiral alkyl halide is :

a

Racemisation occurs in \(S _{ N } 1\) reaction and inversion occurs in \(S _{ N } 2\) reaction.

b

Racemisation occurs in \(S _{ N } 1\) reaction and retention occurs in \(S _{ N } 2\) reaction.

c

Retention occurs in \(S _{ N } 1\) reaction and inversion occurs in \(S _{ N } 2\) reaction.

d

Racemisation occurs in both \(S _{ N } 1\) and \(S _{ N } 2\) reactions.

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

Racemisation occurs in \(S _{ N } 1\) reaction and inversion occurs in \(S _{ N } 2\) reaction.

Explanation

In SN1 reaction, the carbocation intermediate is formed. Since the nucleophile can attack from both sides of the planar carbocation, the product is a racemic mixture (loss of optical purity).

In SN2 reaction, the nucleophile attacks from the backside of the leaving group, leading to inversion of configuration (Walden inversion)

Q22

[JEE Main 2024, 1 Feb (Shift 2)]

b

Oxalic acid

d

Malonic acid
