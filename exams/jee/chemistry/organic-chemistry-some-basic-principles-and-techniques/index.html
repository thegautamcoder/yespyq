Given below are two statements:

Statement I: (CH3)3C⊕ is more stable than CH3C⊕ as nine hyperconjugation interactions are possible in (CH3)3C⊕.

In the light of the above statements, choose the correct answer from the given below

[JEE Main 2026, 23 Jan (Shift 2)]

a

Statement I is false but Statement II is true

b

Both Statement I and Statement II are false

c

Statement I is true but Statement II is false

d

Both Statement I and Statement II are true

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: c)

Statement I is true but Statement II is false

Explanation

Statement I:

(CH₃)₃C⁺ is a tertiary carbocation. It has three methyl groups attached, and each methyl group contains 3 α-hydrogens.
Total α-hydrogens = 3 × 3 = 9

Each α-hydrogen contributes to hyperconjugation, so 9 hyperconjugative structures are possible.
Greater hyperconjugation leads to higher stability.

Therefore, (CH₃)₃C⁺ is more stable than CH₃–C⁺.
Statement I is true.

Statement II:

CH₃⁺ (methyl carbocation) has no adjacent carbon atom, so it has no α-hydrogens.
Hence, number of hyperconjugative structures = 0 (not 3).

Although CH₃⁺ is less stable than (CH₃)₃C⁺, the given reason is incorrect.
Statement II is false.

Given below are two statements:

Statement I: (CH3)3C⊕ is more stable than CH3C⊕ as nine hyperconjugation interactions are possible in (CH3)3C⊕.

In the light of the above statements, choose the correct answer from the given below

a

Statement I is false but Statement II is true

b

Both Statement I and Statement II are false

c

Statement I is true but Statement II is false

d

Both Statement I and Statement II are true

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: c)

Statement I is true but Statement II is false

Explanation

Statement I:

(CH₃)₃C⁺ is a tertiary carbocation. It has three methyl groups attached, and each methyl group contains 3 α-hydrogens.
Total α-hydrogens = 3 × 3 = 9

Each α-hydrogen contributes to hyperconjugation, so 9 hyperconjugative structures are possible.
Greater hyperconjugation leads to higher stability.

Hence, number of hyperconjugative structures = 0 (not 3).

Although CH₃⁺ is less stable than (CH₃)₃C⁺, the given reason is incorrect.
Statement II is false.
