CORRECT order of stability for the following is

CH2=CH−,CH3−CH2−,CH≡C−

b

CH3−CH2−>CH2=CH−>CH≡C−

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

CH≡C−>CH2=CH−>CH3−CH2−

Explanation

These are carbanions, so stability depends mainly on hybridization.

Rule: Greater s-character stabilizes the negative charge more.

sp → 50% s-character
sp² → 33% s-character
sp³ → 25% s-character

So:

CH≡C⁻ (sp) → most stable
CH₂=CH⁻ (sp²) → moderately stable
CH₃–CH₂⁻ (sp³) → least stable

Final order:

CH≡C⁻ > CH₂=CH⁻ > CH₃–CH₂⁻

Q22

Given below are two statements:

Statement I: (CH3)3C⊕ is more stable than CH3C⊕ as nine hyperconjugation interactions are possible in (CH3)3C⊕.

Statement II: CH3⊕ is less stable than (CH3)3C⊕ as only three hyperconjugation interactions are possible in CH3⊕.

In the light of the above statements, choose the correct answer from the given below

[JEE Main 2026, 23 Jan (Shift 2)]

a

Statement I is false but Statement II is true

b

Both Statement I and Statement II are false

c

Statement I is true but Statement II is false

d

Both Statement I and Statement II are true

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: c)

Statement I is true but Statement II is false

Explanation

Statement I:

(CH₃)₃C⁺ is a tertiary carbocation. It has three methyl groups attached, and each methyl group contains 3 α-hydrogens.
Total α-hydrogens = 3 × 3 = 9

Each α-hydrogen contributes to hyperconjugation, so 9 hyperconjugative structures are possible.
Greater hyperconjugation leads to higher stability.

Therefore, (CH₃)₃C⁺ is more stable than CH₃–C⁺.
Statement I is true.

Statement II:

CH₃⁺ (methyl carbocation) has no adjacent carbon atom, so it has no α-hydrogens.
Hence, number of hyperconjugative structures = 0 (not 3).

Although CH₃⁺ is less stable than (CH₃)₃C⁺, the given reason is incorrect.
Statement II is false.

Q33

The interaction between \(\pi\) bond and lone pair of electrons present on an adjacent atom is responsible for

[JEE Main 2024, 29 Jan (Shift 1)]

a

Resonance effect

b

Hyperconjugation

c

Inductive effect

d

Electromeric effect

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

Resonance effect

Explanation

Correct Option: 1 – Resonance effect

Explanation:

The resonance effect arises when there is a π bond (double bond) and a lone pair of electrons on an adjacent atom. This allows delocalization of electrons through overlapping p-orbitals, creating multiple contributing structures (resonating structures) for a molecule.

Example:

In phenol, the lone pair on oxygen interacts with the π electrons of the benzene ring, resulting in resonance.

Steam distillation

Explanation

Essential oils are insoluble in water, soluble in steam and have high vapour pressure. Therefore, they can be separated by steam distillation.
