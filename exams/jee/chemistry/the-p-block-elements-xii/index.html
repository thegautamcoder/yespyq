In SO₂, sulfur has an oxidation number of +4. It acts as a reducing agent by increasing its oxidation number to +6 ( forming H₂SO₄) and as an oxidizing agent by decreasing its oxidation number to 0 ( forming sulfur). Thus, SO₂ shows both behaviors.
