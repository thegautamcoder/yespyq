Q7

Given below are two statements : one is labelled as Assertion (A) and the other is labelled as Reason (R).
Assertion (A) : Cis form of alkene is found to be more polar than the trans form.
Reason (R) : Dipole moment of trans isomer of 2-butene is zero.
In the light of the above statements, choose the correct answer from the options given below :

[JEE Main 2024, 05 Apr (Shift 1)]

a

Both (A) and (R) are true but (R) is NOT the correct explanation of (A)

b

(A) is false but (R) is true

c

Both (A) and (R) are true and (R) is the correct explanation of (A)

d

(A) is true but (R) is false

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: c)

Both (A) and (R) are true and (R) is the correct explanation of (A)

Explanation

Assertion (A): Cis-alkenes are more polar than trans-alkenes.
True (dipoles add in cis form)

Reason (R): Dipole moment of trans-2-butene = 0.
True (dipoles cancel due to symmetry)

Since dipole cancellation in trans form explains why cis is more polar, the reason correctly explains the assertion.

Q9

Number of σ and π bonds respectively in hex-1-en-4-yne are:

Memory Based Question 29/Jan/25 Evening shift

a

13,3

b

14,3

c

3,14

d

14,13

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: b)

14,3

Explanation

Hex-1-en-4-yne (C₆H₈) contains:

  • Sigma (σ) bonds: 14 (4 C–C single bonds, 8 C–H bonds, 1 sigma bond in C=C, and 1 sigma bond in C≡C).
  • Pi (π) bonds: 3 (one from C=C and two from C≡C).

Thus, the correct answer is 14 σ and 3 π bonds.

Q12

The number of paramagnetic species among the following is ...........
\[
B _2, Li _2, C _2, C _2^{-}, O _2^{-2}, O _2^{+} \text {and } He _2^{+} \text {. }
\]

[JEE Main 2022, 28 Jul (Shift 1)]

a

4

b

5

c

6

d

7

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

4

Explanation

Paramagnetic species contain one or more unpaired electrons.

B₂: Configuration leads to two unpaired electrons in π orbitals, so it is paramagnetic.

Li₂: All electrons are paired, so it is diamagnetic.

C₂: All electrons are paired in π orbitals, so it is diamagnetic.

C₂²⁻: Adding two electrons fills antibonding π* orbitals singly before pairing. This results in two unpaired electrons, so it is paramagnetic.

O₂²⁻: All electrons are paired, so it is diamagnetic.

O₂⁺: One electron is removed from antibonding orbital, leaving one unpaired electron, so it is paramagnetic.

He₂⁺: One unpaired electron is present, so it is paramagnetic.
