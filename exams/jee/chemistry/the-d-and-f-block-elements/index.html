Q16

Which of the following electronic configuration would be associated with the highest magnetic moment?

[JEE Main 2024, 27 Jan (Shift 1)]

a

\([ Ar ] 3 d ^7\)

b

\([ Ar ] 3 d ^3\)

c

\([ Ar ] 3 d ^8\)

d

\([ Ar ] 3 d ^6\)

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: d)

\([ Ar ] 3 d ^6\)

Explanation

Magnetic moment is given by:

μ = √[n(n + 2)] BM
(where n = number of unpaired electrons)

Count unpaired electrons using Hund’s rule:

A. [Ar] 3d⁷ → 3 unpaired
B. [Ar] 3d³ → 3 unpaired
C. [Ar] 3d⁸ → 2 unpaired
D. [Ar] 3d⁶ → 4 unpaired

Compare magnetic moments:

n = 4 gives highest value of √[n(n + 2)]

Final Answer:
D. [Ar] 3d⁶

Q24

KMnO4 acts as an oxidising agent in acidic medium. ‘X’ is the difference between the oxidation states of Mn in reactant and product. ‘Y’ is the number of ‘d’ electrons present in the brown red precipitate formed at the end of the acetate ion test with neutral ferric chloride. The value of X + Y is

[JEE Main 2025, 4 Apr (Shift 1)]

a

10

b

11

c

12

d

13

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

10

Explanation

In acidic medium:

MnO₄⁻ → Mn²⁺

Oxidation state changes:

+7 → +2

So, X = 5

Acetate ion test with Fe³⁺:

CH₃COO⁻ + Fe³⁺ → Fe(CH₃COO)₃

This forms brown-red precipitate

Fe³⁺ configuration:

Fe = [Ar] 3d⁶ 4s²
Fe³⁺ → remove 2 (4s) + 1 (3d)

= 3d⁵

So number of d-electrons = 5

Thus, Y = 5

Final value, X + Y = 5 + 5 = 10
