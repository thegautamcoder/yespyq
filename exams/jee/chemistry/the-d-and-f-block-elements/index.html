Q16 FREE PREVIEW

Which of the following electronic configuration would be associated with the highest magnetic moment?

[JEE Main 2024, 27 Jan (Shift 1)]

a

\([ Ar ] 3 d ^7\)

b

\([ Ar ] 3 d ^3\)

c

\([ Ar ] 3 d ^8\)

d

\([ Ar ] 3 d ^6\)

✓ Correct answer: d)

\([ Ar ] 3 d ^6\)

Explanation

Magnetic moment is given by:

μ = √[n(n + 2)] BM
(where n = number of unpaired electrons)

Count unpaired electrons using Hund’s rule:

A. [Ar] 3d⁷ → 3 unpaired
B. [Ar] 3d³ → 3 unpaired
C. [Ar] 3d⁸ → 2 unpaired
D. [Ar] 3d⁶ → 4 unpaired

Compare magnetic moments:

n = 4 gives highest value of √[n(n + 2)]

Final Answer:
D. [Ar] 3d⁶
