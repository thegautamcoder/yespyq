Q3

Alkaline oxidative fusion of \(MnO _2\) gives "A" which on electrolytic oxidation in alkaline solution produces B. A and B respectively are

[JEE Main 2024, 30 Jan (Shift 2)]

a

\(Mn _2 O _3\) and \(MnO _4^{2-}\)

b

\(MnO _4^{2-}\) and \(Mn _2 O _7\)

c

\(Mn _2 O _7\) and \(MnO _4^{-}\)

d

\(MnO _4^{2-}\) and \(MnO _4^{-}\)

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: d)

\(MnO _4^{2-}\) and \(MnO _4^{-}\)

Explanation

Alkaline oxidative fusion of MnO2:

2MnO2+4OH−+O2→2MnO42−+2H2O

Electrolytic oxidation of MnO42− in alkaline medium.

MnO42−→MnO4−+e−

Q6

Among CrO,Cr2O3 and CrO3, the sum of spin-only magnetic moment values of basic and amphoteric oxides is_____×10-2BM (nearest integer).
(Given atomic number of Cr is 24 )

[JEE Main 2024, 06 Apr (Shift 1)]

a

899

b

877

c

878

d

800

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: b)

877

Explanation

CrO Basic oxide
Cr2O3 Amphoteric oxide
In CrO,Cr exist as Cr+2 and have μ only =4.90
In Cr2O3,Cr exist as Cr+3 and have μ only =3.87
Sum of spin only magnetic moment
=4.90+3.87=8.77
μonly =877×10-2
Ans. 877

Q8

The correct decreasing order of spin only magnetic moment values (BM) of Cu+,Cu2+Cr2+ and Cr3+ ions is :

[JEE Main 2025, 8 Apr (Shift 1)]

a

Cu+>Cu2+>Cr3+>Cr2+

b

Cu2+>Cu+>Cr2+>Cr3+

c

Cr2+>Cr3+>Cu2+>Cu+

d

Cr3+>Cr2+>Cu+>Cu2+

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: c)

Cr2+>Cr3+>Cu2+>Cu+

Explanation

Cu+ : [Ar] 3d10 , Spin only magnetic moment = 0 B.M.
Cu+2 : [Ar] 3d9 ,Spin only magnetic moment = 1.73 B.M.
Cr+2 : [Ar] 3d4 ,Spin only magnetic moment = 4.90 B.M.
Cr+3 : [Ar] 3d3 ,Spin only magnetic moment = 3.87 B.M.
Order of µ : Cr+2 > Cr+3 > Cu+2 > Cu+
