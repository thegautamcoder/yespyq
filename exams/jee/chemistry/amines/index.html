Q4

An amine \((X)\) is prepared by ammonolysis of benzyl chloride. On adding p-toluenesulphonyl chloride to it the solution remains clear. Molar mass of the amine \((X)\) formed is ................\(g mol ^{-1}\).
(Given molar mass in \(gmol ^{-1} C : 12, H : 1, O : 16, N : 14\) )

[JEE Main 2024, 6 Apr (Shift 2)]

a

108

b

287

c

330

d

111

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: b)

287

Explanation

Ammonolysis of benzyl chloride can give primary, secondary, and tertiary amines.

In the Hinsberg test:

Primary amine → forms soluble sulphonamide (solution clear in base)
Secondary amine → forms insoluble product (solution turbid)
Tertiary amine → does not react and remains insoluble

Here, the statement says solution remains clear, which in this context indicates tertiary amine (no reaction, remains dissolved).

Thus, X = tribenzylamine = (C₆H₅CH₂)₃N

C₆H₅CH₂ = C₇H₇

So, (C₇H₇)₃N = C₂₁H₂₁N

Molar mass = 21×12 + 21×1 + 14
= 252 + 21 + 14
= 287 g/mol
