A and B are correct.

Q10

For an ideal monoatomic gas undergoing an isobaric process, what is the ratio ΔQΔU\frac{\Delta Q}{\Delta U}? (Shift I - Memory Based)

a

53\frac{5}{3}

b

75\frac{7}{5}

c

43\frac{4}{3}

d

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

53\frac{5}{3}

Explanation

From the first law of thermodynamics for an isobaric process: ΔQ=ΔU+ΔW.\Delta Q = \Delta U + \Delta W.

  • For a monoatomic gas:
    • ΔU=32nRΔT\Delta U = \frac{3}{2} n R \Delta T,
    • ΔW=nRΔT\Delta W = n R \Delta T.
  • Heat supplied: ΔQ=32nRΔT+nRΔT=52nRΔT.\Delta Q = \frac{3}{2} n R \Delta T + n R \Delta T = \frac{5}{2} n R \Delta T.
  • Ratio: ΔQΔU=5232=53.\frac{\Delta Q}{\Delta U} = \frac{\frac{5}{2}}{\frac{3}{2}} = \frac{5}{3}.

Thus, the ratio is 53\frac{5}{3}.

If initial volume of each compartment was 9 litres then the final volume in right-hand side compartment is ______ litres. (for this ideal gas CPCV=1.5 )

c

14

d

Answer & explanation — PYQ Pass

Unlock · ₹149
✓ Correct answer: b)

4

Explanation

Since the walls and the piston are adiabatic, the compression of the gas in the right compartment undergoes a purely adiabatic process. Because the piston is frictionless, the final pressure must be equal in both compartments (Pf=278P).

For the right compartment:

Initial state: Pi=P, Vi=9

Final state: Pf=278P, Vf=?

Given: γ=CPCV=1.5=32

Using the adiabatic equation PiViγ=PfVfγ:

\[P(9)^{\frac{3}{2}} = \left(\frac{27}{8}P\right)(V_f)^{\frac{3}{2}}\]

Cancel \(P\) from both sides and solve for Vf:​

\[(3^2)^{\frac{3}{2}} = \frac{27}{8}(V_f)^{\frac{3}{2}}\] \[27 = \frac{27}{8}(V_f)^{\frac{3}{2}}\] \[1 = \frac{1}{8}(V_f)^{\frac{3}{2}}\] \[(V_f)^{\frac{3}{2}} = 8\] \[V_f = (8)^{\frac{2}{3}}\] \[V_f = (2^3)^{\frac{2}{3}}\] \[V_f = 2^2 = 4\]

The final volume in the right-hand side compartment is 4 litres.

msln⁡T2T1ms \ln \frac{T_2}{T_1}

b

msms

c

msln⁡T1T2ms \ln \frac{T_1}{T_2}

Zero

Answer & explanation — PYQ Pass

✓ Correct answer: a)

msln⁡T2T1ms \ln \frac{T_2}{T_1}

ExplanationEntropy change (ΔS\Delta S) is given by the formula:

ΔS=∫T1T2dQT\Delta S = \int_{T_1}^{T_2} \frac{dQ}{T}​

For a system where the temperature is slowly raised and the specific heat capacity is constant, the heat supplied (dQdQ) is:

dQ=ms dTdQ = m s \, dT

Substituting into the entropy formula:

ΔS=∫T1T2ms dTT\Delta S = \int_{T_1}^{T_2} \frac{ms \, dT}{T}​

This simplifies to:

ΔS=ms∫T1T2dTT\Delta S = ms \int_{T_1}^{T_2} \frac{dT}{T}​

The integral of 1T\frac{1}{T}​ is ln⁡T\ln T, so:

ΔS=ms[ln⁡T]T1T2\Delta S = ms \left[\ln T\right]_{T_1}^{T_2}

​​ ΔS=ms(ln⁡T2−ln⁡T1)\Delta S = ms \left(\ln T_2 - \ln T_1\right)

Using logarithmic properties:

ΔS=msln⁡T2T1\Delta S = ms \ln \frac{T_2}{T_1}​​

Thus, the change in entropy is:

msln⁡T2T1\boxed{ms \ln \frac{T_2}{T_1}}​​​

Unlock this and thousands more solved PYQs.

✓ Correct answer: b)

A, D, E Only

Explanation

From the equation, we get:

PT= constant 

Now, let's break down each statement:
A. The work done by the gas during the process is zero.

Since the volume remains constant, there is no displacement of the gas, and hence no work is done. So, this statement is true.
B. The heat added to the gas is different from the change in its internal energy.
