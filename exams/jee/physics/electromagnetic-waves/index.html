Q3

The value of E0 is 9.3 V/m and c is 3 × 108 m/s. Find the value of B0.

(Shift - II Memory Based)

a

1

b

c

4

d

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: d)

3.1×10-8

Explanation

The relationship between the electric field (E0E_0) and magnetic field (B0B_0) in electromagnetic waves is given by:

E0=c⋅B0E_0 = c \cdot B_0​

Rearranging for B0B_0​:

B0=E0cB_0 = \frac{E_0}{c}​​

Substitute the given values:

B0=9.33×108B_0 = \frac{9.3}{3 \times 10^8}​

Simplify:

B0=3.1×10−8 TB_0 = 3.1 \times 10^{-8} \, \text{T}

Rounding B0B_0​ is approximately 3 (depending on units being normalized for B0B_0​).

Correct answer: (d).

Q6

The electric field in an electromagnetic wave is given by E→=i^40cosω(t-z/c)NC-1. The magnetic field induction of this wave is (in SI unit) :

a

B→=k^40ccosω(t-z/c)

b

B→=j^40cosω(t-z/c)

c

B→=j^40ccosω(t-z/c)

d

B→=i^40ccosω(t-z/c)

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: c)

B→=j^40ccosω(t-z/c)

Explanation

1. Direction: The wave propagates along the \(+z\)-axis (from \(t - z/c\)). The electric field \(\vec{E}\) is along the \(+x\)-axis (\(\hat{i}\)).
The direction of propagation is given by \(\vec{E} \times \vec{B}\).
Since \(\hat{i} \times \hat{j} = \hat{k}\), the magnetic field \(\vec{B}\) must be along the \(+y\)-axis (\(\hat{j}\)).

2. Amplitude: The amplitude of the magnetic field is \(B_{0}=\frac{E_{0}}{c}\).
Given \(E_{0}=40\), so \(B_{0}=\frac{40}{c}\).

Combining these, \(\vec{B}=\hat{j}\frac{40}{c}\cos\omega(t-z/c)\).

Q9

An electromagnetic wave propagates in the +X -direction. Then, the electric field and magnetic field are directed along

a

X, Y

b

Z, Y

c

Y, Z

d

Y, X

🔒
Answer & explanation — Premium

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: c)

Y, Z

ExplanationStep 1: Understanding Electromagnetic Wave Propagation

  • An electromagnetic wave (EM wave) consists of:

    • An electric field (EE)
    • A magnetic field (BB)
    • A wave propagation direction

  • These three quantities are mutually perpendicular following the right-hand rule:

    • If the wave propagates along +X-direction, then:
      • The electric field (EE) is along the Y-axis.
      • The magnetic field (BB) is along the Z-axis.
Step 2: Identifying the Correct Answer
  • Given that the wave propagates in the +X direction:
    • EE is along Y-axis.
    • BB is along Z-axis.

Correct answer:

B(Y,Z)\boxed{B} \quad (Y, Z)
