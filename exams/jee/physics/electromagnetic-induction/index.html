Q2 FREE PREVIEW

A solenoid of radius 10 cm carrying current 0.29 A and having total 200 turns. If magnetic field inside solenoid is\( 2.9 \times 10^{-4} \mathrm{~T}\). Find length of solenoid.(Shift - II Memory Based)

a

\(6 \pi \mathrm{~cm}\)

b

\(8 \pi \mathrm{~cm}\)

c

4.5 cm

d

16 cm

✓ Correct answer: b)

\(8 \pi \mathrm{~cm}\)

Explanation

We are given:

  • Radius of solenoid = r=10r = 10cm (not needed in calculations)
  • Current = I=0.29I = 0.29 A
  • Total number of turns = N=200N = 200
  • Magnetic field inside the solenoid = B=2.9×10−4B = 2.9 \times 10^{-4}

We need to determine the length of the solenoid (LL).

Step 1: Using the Magnetic Field Formula for a Solenoid

The magnetic field inside a solenoid is given by:

B=μ0nIB = \mu_0 n I

where:

  • μ0\mu_0​ is the permeability of free space, μ0=4π×10−7\mu_0 = 4\pi \times 10^{-7}

  • nnn is the number of turns per unit length, given by:

    n=NLn = \frac{N}{L}​

  • II is the current.

Rewriting the equation:

B=μ0NLIB = \mu_0 \frac{N}{L} I

Solving for LL:

L=μ0NIBL = \frac{\mu_0 N I}{B}​

Step 2: Substituting Values

L=(4π×10−7)(200)(0.29)2.9×10−4L = \frac{(4\pi \times 10^{-7}) (200) (0.29)}{2.9 \times 10^{-4}}

​ L=(4π×10−7×200×0.29)2.9×10−4L = \frac{(4\pi \times 10^{-7} \times 200 \times 0.29)}{2.9 \times 10^{-4}}

L=8π cm

Final Answer:

B8π cm\boxed{B} \quad 8\pi \text{ cm}

Q3 FREE PREVIEW

A coil of area A and N turns is rotating with angular velocity ω in a uniform magnetic field B→ about an axis perpendicular to B→. Magnetic flux φ and induced emf ε across it, at an instant when B→ is parallel to the plane of coil, are :

[JEE Main 2025, 29 Jan (Shift 1)]

a

φ=AB,ε=0

b

φ=0,ε=0

c

φ=0,ε=NABω

d

φ=AB,ε=NABω

✓ Correct answer: c)

φ=0,ε=NABω

Explanation

ϕ=BAN·cos(ωt)

ε=-dϕdt=BAωN·sin(ωt)

When B is parallel to plane, ωt=π2

⇒ϕ=0,ε=BAωN
