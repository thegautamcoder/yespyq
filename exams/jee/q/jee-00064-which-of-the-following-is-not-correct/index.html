Which of the following is not correct?
aG is positive for a non-spontaneous reaction
bG is positive for a spontaneous reaction
cG is negative for a spontaneous reaction
dG is zero for a reversible reaction
✓ Correct answer: b) G is positive for a spontaneous reaction
Explanation“ΔG is positive for a spontaneous reaction” is incorrect.For spontaneity ΔG < 0; a positive ΔG indicates non-spontaneity.
