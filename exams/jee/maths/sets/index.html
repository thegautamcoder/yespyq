Q2

Let A={(α,β)∈R×R:|α-1|≤4 and |β-5|≤6} and B=(α,β)∈R×R:16(α-2)2+9(β-6)2≤144. Then

a

B⊂A

b

\(A \cup B=\{(x, y):-4 \leq x \leq 4,-1 \leq y \leq 11\}\)

c

neither A⊂B nor B⊂A

d

A⊂ B

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

B⊂A

Explanation

Set A:

\(A=\{(\alpha, \beta) \in \mathbb{R} \times \mathbb{R}:|\alpha-1| \leq 4\) and \(|\beta-5| \leq 6\}\)

This represents a rectangle with:

−3≤α≤5-3 \leq \alpha \leq 5 (from α−1∈[−4,4]\alpha - 1 \in [-4, 4])

−1≤β≤11-1 \leq \beta \leq 11 (from β−5∈[−6,6]\beta - 5 \in [-6, 6])

Set B:

\(B=\left\{(\alpha, \beta) \in \mathbb{R} \times \mathbb{R}: 16(\alpha-2)^2+9(\beta-6)^2 \leq 144\right\}\)

This is an ellipse centered at (2,6)(2, 6).

Standard form: \(\frac{(\alpha-2)^2}{9}+\frac{(\beta-6)^2}{16} \leq 1\)

So, it has:

Horizontal semi-axis \(= 3\)

Vertical semi-axis \(= 4\)

Hence, the ellipse spans:

α∈[2−3,2+3]=[−1,5]\alpha \in [2 - 3, 2 + 3] = [-1, 5]

β∈[6−4,6+4]=[2,10]\beta \in [6 - 4, 6 + 4] = [2, 10]

Now compare sets:

Rectangle A: α∈[−3,5],β∈[−1,11]\alpha \in [-3, 5], \beta \in [-1, 11]

Ellipse B: completely lies within bounds of A

So, B is a subset of A, but A is not a subset of B (e.g., point (−3,−1)(-3, -1) is in A but not in B)

Q3

Let \(A\) and \(B\) be two finite sets with \(m\) and \(n\) elements, respectively. The total number of subsets of the set \(A\) is \(56\) more than the total number of subsets of \(B\). Then the distance of the point \(P(m, n)\) from the point \(Q(-2,-3)\) is:

[JEE Main 2024, 27 Jan (Shift 2)]

a

10

b

6

c

8

d

4

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: a)

10

Explanation

\(\begin{aligned}
& 2^{\mathrm{m}}-2^{\mathrm{n}}=56 \\
& 2^{\mathrm{n}}\left(2^{\mathrm{m}-\mathrm{n}}-1\right)=2^3 \times 7 \\
& 2^{\mathrm{n}}=2^3 \text { and } 2^{\mathrm{m}-\mathrm{n}}-1=7 \\
& \Rightarrow \mathrm{n}=3 \text { and } 2^{\mathrm{m}-\mathrm{n}}=8 \\
& \Rightarrow \mathrm{n}=3 \text { and } \mathrm{m}-\mathrm{n}=3 \\
& \Rightarrow \mathrm{n}=3 \text { and } \mathrm{m}=6 \\
& \mathrm{P}(6,3) \text { and } \mathrm{Q}(-2,-3) \\
& \mathrm{PQ}=\sqrt{8^2+6^2}=\sqrt{100}=10
\end{aligned}\)

0

Explanation

Let (3+2)x=t

⇒13−2x=t

⇒(3−2)x=1t

⇒t+1t=10

⇒t2−10t+1=0

Q8

Let A={1,6,11,16,…} and B={9,16,23,30,…} be the sets consisting of the first 2025 terms of two arithmetic progressions. Then n(A∪B) is

a

3814

b

4027

c

3761

d

4003

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: c)

3761

Explanation

Set A is an AP with:

first term = 1, common difference = 5

General term of A:

a = 1 + 5k

Set B is an AP with:

first term = 9, common difference = 7

General term of B:

B = 9+7m

Number of elements in A = 2025

Number of elements in B = 2025

To find common elements, solve:

1+5k = 9+7m

5k – 7m = 8

One solution is k = 3, m = 1 giving common element 16 .

LCM of 5 and 7 = 35, so common elements form an AP:

16, 51, 86, …

Largest common element possible within first 2025 terms:

Last term of A = 1+2024 × 5 = 10121

Common terms are 16+35r≤10121

35r≤10105

r≤288

Hence number of common elements = 289.

Therefore,

nA∪B=nA+nB−nA∩B

= 2025 + 2025 –289 = 3761

Answer: 3761

Q10

Let \(A=\{n \in[100,700] \cap N: n\) is neither a multiple of 3 nor a multiple of 4\(\}\). Then the number of elements in \(A\) is

a

280

b

300

c

310

d

290

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: b)

300

Explanation

The total number of integers is \(700-100+1=601\)

The number of multiples of 3 between 100 and 700 \(=200\)

The number of multiples of 4 between 100 and 700 \(=151\)

The number of multiples of 12 between 100 and 700 \(=50\)

Required Count is \(601-200-151+50=300\)
