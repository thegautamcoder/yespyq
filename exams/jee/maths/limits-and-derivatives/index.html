\(\begin{equation}
\lim _{x \rightarrow \infty}\left(\left(\frac{e}{1-e}\right)\left(\frac{1}{e}-\frac{x}{1+x}\right)\right)^x=\alpha, \text { find } \frac{\ln \alpha}{1+\ln \alpha}
\end{equation}\) (22 Jan, Shift II, Memory Based)

a

1-e

b

e

c

1+e

d

2+e

Answer & explanation — PYQ Pass

✓ Correct answer: b)

e

Explanation

\(\begin{aligned}
& \lim _{x \rightarrow \infty}\left(\left(\frac{e}{e-1}\right)\left(\frac{1}{e}-\frac{x}{1+x}\right)\right)^x \\
& \lim _{x \rightarrow \infty}\left(\left(\frac{1}{e-1}-\frac{e x}{(e-1)(x+1)}\right)^x\right) \\
& \alpha=e^{\lim _{x \rightarrow \infty}\left(\frac{1}{e-1}-\frac{e x}{(e-1)(x+1)}-1\right)x} \\
& \ln (\alpha)=\lim _{x \rightarrow \infty}\left(\frac{e }{(1-e)}-\frac{ex}{(1-e)(1+x)}\right) x \\
& \lim _{x \rightarrow \infty} \frac{ex}{(1-e)(1+x)}=\frac{e}{1-e} \\
& \text { Now, } \frac{\ln \alpha}{1+\ln \alpha}=\frac{\frac{e}{1-e}}{1+\frac{e}{1-e}}=e
\end{aligned}\)

Explanation

Q21

Let limx→2(tan(x-2))rx2+(p-2)x-2p(x-2)2=5 for some \(r, p \in R\). If the set of all possible values of \(q\), such that the roots of the equation rx2-px+q=0 lie in (0,2), be the interval (α,β], then 4(α+β) equals:

[JEE Main 2026, 6 Apr (Shift 2)]

a

\(11\)

b

\(13\)

c

\(17\)

d

\(21\)

🔒
Answer & explanation — PYQ Pass

Unlock this and thousands more solved PYQs.

Unlock · ₹149
✓ Correct answer: c)

\(17\)

Explanation

\(\lim _{x \rightarrow 2} \frac{\tan (x-2)}{x-2} \cdot \frac{r x^2+(p-2) x-2 p}{x-2}=5\)

Since \(\lim _{x \rightarrow 2} \frac{\tan (x-2)}{x-2}=1\), we need

\(\lim _{x \rightarrow 2} \frac{r x^2+(p-2) x-2 p}{x-2}=5\)

For the limit to be finite,

\(4 r+2(p-2)-2 p=0 \Rightarrow 4 r-4=0 \Rightarrow r=1\)

Now \(x^2+(p-2) x-2 p=(x-2)(x+p)\)

So \(\lim _{x \rightarrow 2}(x+p)=5 \Rightarrow 2+p=5 \Rightarrow p=3\)

The quadratic equation becomes \(x^2-3 x+q=0\)

For real roots, \(\Delta \geq 0 \Rightarrow 9-4 q \geq 0 \Rightarrow q \leq \frac{9}{4}\)

For both roots to lie in \((0,2)\), \(f(0)=q>0\) and \(f(2)>0\)

\(f(2)=4-6+q=q-2>0 \Rightarrow q>2\)

So, \(q \in\left(2, \frac{9}{4}\right]\)

Thus, \(\alpha=2, \beta=\frac{9}{4}\)

\(4(\alpha+\beta)=4\left(2+\frac{9}{4}\right)=17\)
